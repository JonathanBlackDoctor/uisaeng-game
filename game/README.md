# 의생게임 개발 미리보기

React + TypeScript + Vite, IndexedDB 기반 로컬 웹 통합 빌드입니다. **완성 게임이 아닙니다.** 승인된 표시 스탯 건강·행복·지식·관계를 사용합니다. 새 이야기는 서로 다른 출발 배경과 월별 무작위 사건을 가진 연속 시간 미리보기로 시작하며 중요한 선택에서 멈춥니다. 기존 일상 사건 4개 및 과팅·소개팅·CC와 연애·결혼·육아 창작 사건 14개를 연결한 가족 미리보기의 저장도 이어갑니다. 분포·확률·스탯·진행 간격은 시험값입니다. 26개 전공과 정식 사건은 제공하지 않습니다. 기존 콘텐츠 상태는 `src/content-manifest.json`, 새 경로의 범위와 한계는 [무작위 인생 기록](../docs/random-life-preview.md)에 명시했습니다.

## 실행

Node 22 이상 및 pnpm 사용:

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

잠금 파일은 pnpm-lock.yaml입니다. React/Vite 의존성은 이 폴더에만 설치됩니다. `dev` 및 `preview`는 127.0.0.1에만 바인딩합니다. 공개 호스팅은 포함하지 않습니다.

## 동작과 계약

- `GameState`, `GameAction`, `GameEvent`, `SaveEnvelope`는 `src/contracts.ts`의 TypeScript 인터페이스입니다.
- `reduceGame`은 시간·스토리지에 접근하지 않는 seeded 순수 함수입니다. 중복 action ID와 오래된 event ID를 무시합니다.
- 활동 결과와 미해결 사건을 함께 저장합니다. 사건 처리 후 저장 성공이 확인되어야 화면 상태가 바뀝니다.
- 비교 후 저장(CAS)으로 다른 탭의 오래된 상태가 최신 기록을 덮어쓰지 못하게 합니다. 오류 시 `저장 기록 다시 읽기`로 복구합니다.
- 완료 상태와 회고는 단일 IndexedDB 트랜잭션입니다. run ID로 회고 중복을 방지합니다. 새 시작은 확인 대화상자 이후에만 진행하며 기존 완료 회고를 유지합니다.
- 저장 오류·손상·알 수 없는 버전은 이전 데이터를 그대로 보존합니다. 원본 JSON 백업 다운로드를 제공합니다. 가져오기·버전 마이그레이션은 아직 제공하지 않습니다. 저장 봉투 버전은 1을 유지하며 기존 fixture-v1·family-preview-v1 저장은 원래 경로로 이어갑니다. 새 이야기는 random-preview-v1로 시작합니다.
- 무작위 경로는 19세 의대 입학부터 시작하며 시드·경과 시간·활동·누적 선택·상대와 자녀 상태를 저장합니다. 기본 1초에 게임 속 한 달, 1·2·4·8배속 및 단계 경계 72·144·564·684개월은 임시값입니다. 실제 시험·자격 판정은 구현하지 않았습니다.
- 앱을 닫아 둔 시간 때문에 상태가 진행되지 않습니다. 데이터는 해당 브라우저·출처에만 저장됩니다. 클라우드 동기화는 없습니다.

## 검증과 남은 작업

사건 선택 화면은 검토한 근거가 있을 때만 출처로 연결되는 근거 한 줄을 표시합니다. 제목·추가 설명·펼침 영역은 없으며, 근거가 없으면 아무것도 표시하지 않습니다(2026-10-12 사용자 확정 지시). `src/evidence.ts`는 근거를 사건 맥락에 연결하며 원본 경로·SHA-256·근거 표기 규칙 버전을 보존합니다. 현재 CC의 캠퍼스·동아리 장면 2개에 단일 학교 연구의 동아리 배경 자료 1건만 연결했습니다. 연애 결과의 근거가 아니며, 선택지의 스탯 증감은 별도 게임 조정값입니다.

Vitest + fake-indexeddb로 reducer 결정성·중복 선택·4단계 연결 및 저장 재개·동시 탭·원자성·중복 회고·손상/구버전 보존을 검증합니다. 2026-10-12 무작위 경로 21개를 포함한 게임 테스트 43개, TypeScript 검사와 Vite 빌드가 통과했습니다. 실제 브라우저 PC·390×844에서 시작 배경·시간·배속·사건 중 정지·새로고침 복원·선택·기록을 확인했습니다. 별도의 실제 탭 전환 시험은 미실행입니다. 생산 규칙·전공별 사건·30~45분 플레이 및 원래 저장 설계의 12개 시나리오 전부를 충족했다고 주장하지 않습니다. 보류된 기존 초안 3건은 통합에 포함하지 않습니다.

연애와 가족의 구현 범위 및 남은 항목은 [상세 기록](../docs/romance-family.md)을 참고하세요.
