# 플레이 그림과 동작 확장

2026-10-14. 사용자가 애니메이션 확장 요청 뒤 “이미지와 디자인 종류”를 뜻했다고 정정하고 다양한 그림도 요청했다. 기존의 단순한 SVG 그림체를 유지한 로컬 구현이다.

## 그림

- 열람실·캠퍼스·병동·진료실·연구실·작업 공간·집·휴게 공간·공원·부대 생활관·군 진료실·보건지소에 기본/나무/파랑 3가지 시각적 버전을 제공한다. 총 36개 장소/버전 조합이며, 서로 완전히 다른 그림 36장을 의미하지 않는다. 공통 인물·창문·책상은 재사용한다. 생활관은 관물대·침구 배색 변형이다.
- 아치 서가/낮은 서가, 둥근 소파/파란 소파, 벽돌/유리 캠퍼스, 정자/연못 공원, 연구실 실험대·자료판, 준비실 게시판, 휴게실 음료대, 임상 공간 수납장/카트 등을 추가했다.
- 인물 머리 4종. 주인공/상대/자녀는 각기 다른 변형을 사용하며 노년의 회색 머리와 군 생활관의 짧은 머리를 유지한다. 성별·질환을 외모에서 추정하지 않는다.
- `SceneDesign.tsx`의 순수 함수가 기존 seed와 장소에서 버전을 정한다. 저장·게임 RNG·시간·규칙을 변경하지 않는다. 26개 기존 전공 장비와 실제 가족·활동 소품을 보존한다.
- 비교 페이지: `http://127.0.0.1:5248/game/tests/browser/scene-design.html`. 12개 장소, 세 버전 나란히 보기, 계절·머리·가족·움직임 토글. 여기의 가족 설정은 격리된 시연이며 사용자 저장을 읽거나 수정하지 않는다.

## 함께 구현한 동작

필기·책장 넘김·타이핑, 대화 손짓/듣기 고개 동작의 시간차, 휴식 자세, 어린 자녀와 공, 꽃잎·새·햇빛·실험실 기포·장비 화면을 추가했다. CSS 시계만 사용한다. 선택 대기에서는 caller의 running 값과 무관하게 지속 동작이 정지하며, 숨은 인물도 멈춘다. 모션 감소 CSS를 유지한다.

## 남은 검증과 배포

최종 전체 TypeScript 검사는 동시 작업 중인 `game/tests/career-records.test.tsx:107`의 string/UUID 템플릿 타입 불일치 1건으로 실패했다. 해당 파일은 수정하지 않았다. 앞선 전체 검사에서 발생한 clinic 타입 오류와 구분한다. 전 생애 플레이·모든 조합의 시각 검수·실제 OS 모션 감소 전환은 이번에 실행하지 않았다. 공개 배포와 규칙 확정은 하지 않았다. 소스와 비교 미리보기에 반영했으며, 통합 담당은 최종 고정본에서 전체 검수 후 배포해야 한다.
