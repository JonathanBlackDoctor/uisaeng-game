# 나이·건강과 은퇴

2026-10-15 통합 후속: 사용자가 변경 가능한 시험 연금 수입 추가와 금액 명시를 승인했다. 은퇴 후 기준 월 150만원을 기존 급여 경제 배율에 맞춰 지급하며, 재정 화면에 기준액과 실제 월수입을 표시하고 원장에 연금을 남긴다. `ECONOMY_RULES.retirementIncome`은 변경 가능한 게임 조정값이며 현실의 연금·수급권을 나타내지 않는다. 자동대출이나 미납 삭제는 추가하지 않는다. 은퇴 소득 0원으로 인한 자금 선택 반복을 실제 수입으로 해결한다.

2026-10-15 사용자 요청: 늦은 입학에서는 노화까지 남은 시간이 줄어야 하며, 건강이 나쁘면 노화와 은퇴도 빨라져야 한다.

입학 후 경과 기간 대신 입학 나이와 복무 기간을 포함한 실제 나이를 기준으로 계산한다. 건강 부담이 없는 기본 은퇴는 67세, 회고는 77세다. 20세 입학과 24세 입학은 같은 나이에 은퇴하므로 후자의 입학 이후 활동 기간이 4년 짧다. 늦은 입학·복무·수련 지연으로 은퇴 나이를 뒤로 밀지 않는다. 교육·수련 종료 이후 최소 한 달은 확보한다.

건강 40 미만인 한 달마다 노화 부담 1개월, 20 미만이면 2개월이 누적된다. 최대 120개월이다. 누적 부담은 노화 판정과 은퇴 시점을 앞당긴다. 건강이 40 이상으로 회복되면 추가 누적이 멈추며 이미 쌓인 부담은 유지된다. 순간적인 건강 하락만으로 바로 은퇴하지 않는다. 기본 은퇴가 67세인 경우 최대 57세로 앞당겨질 수 있다.

실제 나이와 누적 부담을 더한 노화 판정 나이가 45세부터 매년 건강에 1점의 부담을 주고, 이후 10년마다 1점씩 증가한다. 기록에는 실제 건강 감소량을 남긴다. 주인공의 기존 60세 외형 변화에도 노화 판정 나이를 쓴다. 화면 나이는 계속 실제 나이를 표시하며 플레이어 스탯은 건강·행복·지식·관계 네 가지다. 경력 화면에 예상 은퇴 나이를 표시하고 건강으로 앞당겨졌을 때 짧게 이유를 알린다.

모든 수치와 상한은 `AGING_RULES`의 변경 가능한 게임 시험 설정이다. 실제 생물학적 나이·의학적 예측·현실 정년을 나타내지 않는다. 방향만 사용자 확정이며 세부 수치는 확정으로 기록하지 않는다. 회고는 사망 판정이 아니다.

새 게임에 적용하며, 노화 상태가 없는 진행 중 저장은 다음 시간 진행부터 적용한다. 과거 건강을 추정해 소급 누적하지 않는다. 이미 은퇴한 구형 저장은 기존 진행 시점을 유지한다. 선택 대기·일시정지 중에는 노화가 진행되지 않는다. 노화 상태와 은퇴 시점은 저장되며, 은퇴 이후 회복해도 경력 단계로 돌아가지 않는다. 병원 정리와 은퇴 이후 사건도 변경된 은퇴 시점에 연결한다.
