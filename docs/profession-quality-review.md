# 직군 확장 비교 검수

2026-10-15 KST. 의과를 기준으로 치과·한의과·간호의 진행, 선택, 경력 연결과 화면을 비교하고 확인한 차이를 수정했다. 신규 직군의 선택 과밀과 일반적인 후속 문구가 줄었고, 연구·은퇴 연결과 저장된 기록의 표시가 개선됐다. 모든 경로나 주관적 재미가 의과와 같다고 확정한 결과는 아니다.

## 같은 시작값 비교

여성 캐릭터, 같은 시작값과 선택 방침으로 네 직군의 기본·길게 분량을 각각 실행했다. 수정 전 표는 시작값 3의 최초 검수 결과이며, 이번 수정 후 결과를 대신하는 자료로 쓰지 않았다.

| 직군 | 기본 수정 전 시작값 3 | 기본 수정 후 시작값 3 | 기본 수정 후 시작값 42 | 길게 수정 후 시작값 3 / 42 |
|---|---:|---:|---:|---:|
| 의과 | 39 | 39 | 44 | 40 / 48 |
| 치과 | 56 | 43 | 45 | 49 / 53 |
| 한의과 | 56 | 43 | 45 | 49 / 53 |
| 간호 | 46 | 38 | 47 | 45 / 55 |

숫자는 생애 전체의 선택 횟수다. 표본이 두 개이므로 전체 난이도 분포나 평균 플레이 시간을 뜻하지 않는다. 직군별 학교·수련 기간도 서로 다르다. 간호 초기 적응의 선택 수를 의과 수련과 억지로 같게 맞추지 않았다.

현재 공통 시간 설정에서 1배속에 해당하는 엔진 진행량은 기본 의·치·한 약 25.1분, 간호 약 24.3분이다. 선택을 읽거나 일시정지하는 시간은 제외했다. 이는 실제 1배속으로 끝까지 기다린 실측 시간이 아니다. 검수 도중 다른 공유 변경으로 `pacing.ts`의 시간이 달라졌으며 이를 보존했다. 따라서 수정 전후 시간을 통제된 실험처럼 비교하지 않는다.

## 수정한 차이

- 기본·길게의 직업 장면 빈도와 상한을 나눴다. 학업 초반에는 기초 실습, 후반에는 졸업 준비가 나오도록 시기를 구분했다.
- 분야의 실습 → 업무 → 개선 순서를 연결했다. 앞서 남긴 기록을 활용하는 실제 선택을 열고, 인계와 회복을 선택했을 때는 같은 선택을 열지 않는다. 선택한 행동과 후속 기록도 구체적으로 남긴다.
- 연구 초기 교육, 자료 수집, 심사 의견, 후배 발표와 직군별 은퇴 장면 18개를 추가했다. 기존 198개와 합쳐 새 게임의 장면 풀은 216개다. 한 판에 전부 나오지 않는다.
- 연구 경로와 간호 보험심사·교육·관리 경로에서 맞지 않는 병상·진료 장면을 제외했다. 부서 이동 뒤 새 분야를 배우고 기존 실무 경력과 전문자격을 따로 유지한다.
- 과거 선택 설명은 기존 ‘이전 선택’ 펼침 안에 넣었다. 긴 목록에서 보조 접근성 문구가 선택창 바깥 스크롤을 움직이던 문제를 수정했다.
- 간호 성과와 회고의 ‘누적 진료’를 ‘누적 돌봄’으로 통일했다. 회고 목록에 직군을 표시하고 직업 기록에 실제 게임 나이를 붙였다.
- 부서 이동·반복 지원의 직업 기록 ID 충돌을 막았다. 기존 중복 ID의 기록은 삭제하지 않고 표시 키로 구분한다. 회고 공유와 전체 기록 컴포넌트가 같은 키를 쓰던 문제도 수정했다.

치과 일반 수련 48개월·통합치의학과 36개월, 한의과 48개월, 간호 실무 분야 19개와 전문자격 13개의 구분은 유지했다. 급여·선발·사건·교육비·장면 간격은 변경 가능한 시험 설정이다. 핵심 규칙을 정식 승인받았다고 기록하지 않았다.

## 실제 브라우저에서 확인한 범위

기존 로컬 검수 서버와 현재 제공된 Codex 브라우저를 사용했다. 거절된 접근을 다른 포트나 도구로 우회하지 않았다. 공개 사이트의 저장은 조작하지 않았다.

| 실제 생애 | 확인한 흐름 | 완료 기록 |
|---|---|---:|
| 간호 | 응급실 취업 → 주간 근무 → 응급 전문교육·평가 → 보험심사 이동 → 은퇴·회고 | 533 |
| 치과 | 통합치의학과 36개월 → 자격 평가 → 봉직 → 수련 기록 활용 → 은퇴·회고 | 556 |
| 한의과 | 국가시험 → 연구 초기 교육 → 연구·교육 심사 → 후속 연구 장면 → 은퇴·회고 | 471 |

실제 UI의 ‘다음 선택’을 사용해 기다리는 구간을 건너뛰었다. SSR이나 자동 생애 실행을 GUI 완주로 표현하지 않았다. 의과는 실제 새 게임과 초기 동아리·프로젝트·동기 선택을 비교했고, 전체 생애 비교는 자동 실행으로 확인했다.

1280×900, 390×844, 320×740 화면에서 확인했다. 간호 19번째 분야까지 Tab으로 접근했고, 두 자리 숫자 단축키로 10번 응급실을 골랐다. Esc로 접고 다시 펼쳐도 선택이 유지됐다. 가로 넘침이 없었고, 보이는 인물의 재생 중 움직임과 일시정지 상태를 확인했다.

일시정지 저장과 치과의 연결된 선택창을 새로고침으로 복구했다. 세 회고가 보관함에 남고, 간호 실무 2/19·응급 전문자격 1/13, 치과 전문의 1/11이 도감에 유지됐다. 한의과 연구 경로에는 취득하지 않은 전문과목이 기록되지 않았다. 기존 중복 기록을 가진 간호 회고를 최종 코드로 다시 연 뒤 새 콘솔 경고·오류는 0건이었다.

## 검증 근거와 제한

[검증 요약](../.orchestrator/profession-quality-v1/final-validation.json), [현재 생애 비교](../.orchestrator/profession-quality-v1/final/comparison.json), [브라우저 조작 기록](../.orchestrator/profession-quality-v1/browser-validation.json), [최종 소스 해시](../.orchestrator/profession-quality-v1/delivery-source-hashes.json)에 근거를 보존했다.

관련 검사 149개 통과 후 기록·화면 수정에 영향을 받는 66개를 재검했다. 파일·테스트 이름·매개변수 발생 순서로 최신 결과를 합치면 160개가 통과했고 미해결 실패는 없다. 최종 회고 키 수정은 실제 브라우저, 타입 검사와 빌드로 확인했다. 기존 656개 전면 회귀와 Node 모듈 전체를 다시 실행했다고 주장하지 않는다. 최종 JS 묶음은 약 940 kB이며 Vite의 500 kB 권고 경고가 남는다.

기존 `experienceVersion` 없는 직군 저장은 기존 장면 규칙과 열린 선택을 유지한다. 새 게임은 `experienceVersion: 1`의 개선된 흐름을 쓴다. 실제 휴대폰의 터치·브라우저 검증, 여러 시작 배경과 선택 전략에 걸친 소득·난도 조정은 남아 있다. 의과의 동아리별 장기 프로젝트와 기관별 교육 분기는 여전히 다른 폭을 가진다.

연구 원본, 다른 HQ·hold·사용량 감시기는 변경하지 않았다. 추가 채팅·에이전트·초기화·유료 구매·공개 배포는 하지 않았다.
