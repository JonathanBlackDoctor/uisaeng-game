# 의생게임 1.3.1

사용자 지시 ‘짧은걸 기본으로 지금거를 긴 걸로 해서 배포’에 따른다.

- 새 게임의 한 판 분량은 이전 짧게 모드를 기본으로 선택하고 ‘기본’으로 표시한다.
- 이전 기본 모드는 ‘길게’로 표시하며 선택할 수 있다.
- 두 모드의 시간·사건 계수와 내부 저장 식별자는 유지한다. 이미 시작한 게임의 분량은 바꾸지 않는다.

1.3.0의 다른 변경은 그대로 포함한다. 검증과 배포 상태는 `docs/release-1.3.1-verification.md`와 `.orchestrator/github-sync/release-1.3.1-state.json`에 기록한다.
