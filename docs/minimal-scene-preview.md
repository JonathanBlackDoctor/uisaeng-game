# 미니멀 생활 장면과 연속 전환

2026-10-14 KST. 사용자 승인: 작은 무대 같은 2D 장면, 재사용하는 가구·인물, 자연스러운 자세·장소 전환을 구현한다. 이 문서는 화면 구현 기록이며 시간 배율이나 사건 규칙의 새 승인이 아니다.

## 구현

- `LifeScene.tsx`: 고정 시점의 창문·책상·인물. 열람실, 병동, 진료실, 연구실, 지원 준비 공간, 집, 휴게 공간을 소품과 색으로 구분한다. SVG와 CSS만 사용하며 새 의존성·외부 이미지·폰트 요청은 없다.
- 인물 DOM을 유지해 위치·상체·머리·팔을 보간한다. 반복 필기/대화 손동작, 호흡, 눈 깜빡임, 창밖 나무와 구름, 컵의 김을 사용한다. 이동 중 짧은 발동작을 적용한다. 배속을 애니메이션 시간에 곱하지 않는다.
- 계절은 실제 시간 3초마다 최신 월을 읽고 2.4초 동안 색을 연결한다. 지나간 계절을 큐에 쌓지 않는다. 멈추면 현재 계절로 맞춘다. 표시 날짜·계절명은 실제 상태를 즉시 반영한다.
- 일시정지/선택 대기에는 지속 모션을 정지한다. 이미 시작한 자세·등장 전환은 마저 안정된다. OS의 모션 감소 설정에서는 모션·전환을 제거한다.
- `scene-state.ts`: 저장된 연결 사건 결정에서 노트 상태와 실제 등장인물을 읽는다. 노트 사건에 상대가 등장하고, 맡으면 노트가 남으며 잠시 함께 작업한다. 거절하면 노트가 사라진다. 저장 형식·게임 난수·규칙을 변경하지 않는다.
- 현재 `progress.focus`를 장면에 연결한다. 구형 `life.focus`만 보던 문제를 수정해 휴식은 집, 연구 활동은 연구실로 반영한다. 활동을 직접 변경하면 이전 선택의 일시적 반응을 해제한다.
- 실제 가족 상태에 있는 배우자/연인·자녀만 집/휴게 공간에 표시한다. 동료와 가족을 동일 인물로 표시하지 않는다.
- `scene-layout.css`: 기존 230px 장면 높이 제한을 해제했다. PC 선택창은 오른쪽에, 모바일은 아래쪽에 배치한다. 모바일 선택 대기에는 동일 SVG를 상단에 유지하고 선택창 내부를 스크롤한다. 기존 포커스 관리·중복 선택 방지·700ms 입력 보호를 유지한다.

## 검증

- 앱 전체 소스와 이번 장면 테스트의 TypeScript 검사 통과. `.orchestrator/scene-tsconfig.json`은 기존 설정을 상속하고 별도 작업 중인 테스트 파일을 제외한 검수 설정이다.
- `scene-state.test.tsx` 7건, `storyline.test.ts` 13건, `storage.test.ts` 9건: 총 29건 통과.
- 최종 Vite 번들 생성 통과: `.orchestrator/scene-build-final/`. JS 683.47 kB, gzip 218.20 kB. 기존 큰 청크 경고는 남아 있다. 공유 작업 폴더의 다른 변경도 포함된 빌드이므로 장면 변경의 증가량으로 해석하지 않는다.
- 별도 5208 로컬 포트에서 실제 새 게임 → 동아리 선택 → 휴식/연구 활동 변경 → 새로고침 복원 확인. 실제 선택 대기 ‘조별 과제의 빈자리’도 새로고침 후 동일하게 복원. 콘솔 warning/error 0.
- 격리 브라우저 장면에서 노트 사건의 참여·거절, 가족 표시, 연구실 소품 확인. 연속 전환 검사에서 동일 주인공 DOM 유지, 중간 자세 보간, 마지막 study 자세, 가로 넘침 없음 확인. 일시정지 시 반복 모션 8개 조회 결과 모두 paused.
- 모바일 390×844 실제 게임: 장면 하단 246.62px, 선택창 상단 295.84px로 겹침 없음. 가로 넘침 없음. 선택창의 아래 선택지 스크롤 확인.
- 증거: `.orchestrator/ui-qa/minimal-scene/game-desktop.jpg`, `game-mobile.jpg`. 격리 검수 페이지: `/game/tests/browser/life-scene.html`.

## 검증 한계와 남은 범위

- 전체 `tsc -b`는 공유 작업 폴더의 `ability-debug.test.ts`, `event-design.test.ts` 타입 오류로 당시 미통과했다. 이번 장면 파일의 타입 오류는 없으며 별도 앱 검사로 확인했다.
- 함께 실행한 `time-controls.test.ts` 7건 중 1건(`preserves monthly money and RNG across a complete career using only next-choice`)이 pendingEvent null로 실패했다. 해당 시간 진행/엔진 파일은 이번 작업에서 수정하지 않았다. 실패를 숨기거나 전체 회귀검사 통과로 표시하지 않는다.
- OS 모션 감소 미디어 규칙은 구현했으나 실제 OS 설정 전환 검수는 하지 않았다. 모든 전공·사건의 개별 연출, 소리, 세밀한 피로·주거 표현은 이번 구현 범위가 아니다. 전 생애 완주를 새로 인증하지 않는다.
- 공개 배포는 실행하지 않았다. 로컬 게임과 미리보기에서 확인할 수 있다.
