# 시작 배경과 가정 형편

## 현재: 편차를 적당히 넓힌 v3

2026-10-13 후속 사용자 지시 “수치간 편차를 더더 높여”와 “너무 극단적으로 높이진 말고”를 함께 반영했다. 새 게임은 profile v3를 사용한다. v1·v2 저장의 배경 생성·능력 초기화·지원금 곡선은 보존한다. 아래 v2 표는 이전 버전의 기록이다.

기본 스탯의 무작위 편차는 ±15→±20, 배경 보정은 ×1.2. 일반 상세 능력의 배경 보정 전 기본 범위는 25~60→20~65, 전문 능력 5종은 8~30→6~32이며 배경 보정은 ×1.2다. 0~100 범위와 자격·경험 제한은 유지한다. 가족 분위기에 따른 지속 피로와 별도의 후반 스탯 회복 조정은 바꾸지 않는다.

지원 성향은 넉넉히 ×1.5 / 가능한 만큼 ×1 / 자립 권유 ×0.35. 1만 원 단위 반올림 후 시작 자금은 4만~9억 원, 월 지원은 0~900만 원. 백분위 추첨·지급 시점·중복 방지·졸업 뒤 중단은 v2와 같다. 현실 가계 통계가 아닌 provisional 게임 설정이다.

v3 검증(2026-10-13): Vitest 240개 범위 확인. 진로 41개 통과; 나머지 199개 중 업무 건강 순손실의 고정값을 가정하던 2개 검사를 상태별 회복과 양립하도록 수정하고 관련 93개 재검증 통과. 해당 검사는 업무 사건 자체의 건강 −2를 기록에서 정확히 확인하고, 최종 건강은 기본 일정보다 낮은지 검증한다. 기존 통합 저장 검사 콜백에 타입 주석을 추가했다. 타입 검사·빌드 통과, 번들 크기 안내는 유지. 2,000개 동일 시드 비교에서 건강 표준편차 증가 비율은 1.1~1.5 범위이며 초기 건강 0 없음. v2 백분위·기존 지원액·IndexedDB 복원 검증 통과. 이번 후속은 수치·버전 호환 조정으로 화면 구조 변경 및 추가 브라우저 검수는 없고, 공개 배포도 하지 않았다.

## v2 구현 기록

2026-10-13 사용자 요청: 배경 후보와 영향 확대, 가정 형편을 상위 백분위로 무작위 결정하고 제공 자원을 수치적으로 차등화. 구조 구현 승인과 상세 수치의 장기 균형 승인은 구분한다.

새 이야기의 `life.background.profile.version=2`. 기존 배경이 없던 저장에 새 프로필을 부여하지 않는다. 원래 `generateStart(seed, 1)`의 추첨 순서·보정을 그대로 유지하고 저장 검증도 해당 버전을 사용한다. 새 프로필과 지급액은 같은 시드로 재현된다. 기존 연구 원본은 사용·변경하지 않았다.

## 새 배경

- 지역 6종, 성장환경 최대 5종, 가정 형편 1,000단계(상위 0.1~100%), 경제 지원 성향 3종, 가족 분위기 5종, 학습환경 5종, 성장기 건강 4종, 이전 경험 10종.
- 가정 형편은 0.1% 간격 균등 추첨이다. 지역·경제적 지원 성향·가족 분위기·학습환경·건강·경험은 각각 추첨한다. 의대 입학생이나 한국 가구의 실제 소득·자산 분포를 재현한 것이 아니다.
- 경제력은 능력·행복을 직접 보정하지 않는다. 기존의 가정 형편에 따른 지식 ±3은 구버전 저장 생성에만 남는다.
- 모든 이전 경험은 기본 스탯과 상세 능력에 영향을 준다. 경험별 관련 능력 +15, 학습환경의 관련 능력 +10, 성장기 건강과 가족 분위기의 보정을 더한다. 값은 0~100 안으로 제한한다. 실력은 기존 활동 성과·사건·전공 준비 계산에 연결된다.
- 가족 분위기는 대학 재학 중 3개월마다 피로를 보정한다: 따뜻함 −2, 거리감 +1, 성적 기대 +2, 자율 −1, 안정 −1. 기존 피로 범위 0~24를 유지한다.
- 지역과 성장환경은 배경 서술이며 별도 능력·소득 우열을 부여하지 않는다. 강원·제주에서 대도시를 제외하던 기존 후보 제한은 유지했다.

## 가족 지원

아래는 지원 성향이 ‘가능한 만큼 보태주는 집’일 때의 조정용 기준값이다. 기준점 사이는 선형 보간하고 1만 원 단위로 반올림한다.

| 가정 형편 | 입학 자금 | 월 지원 | 학기 지원 |
| --- | ---: | ---: | ---: |
| 상위 0.1% | 3억 원 | 500만 원 | 1,000만 원 |
| 상위 1% | 1억 원 | 300만 원 | 800만 원 |
| 상위 5% | 5,000만 원 | 200만 원 | 600만 원 |
| 상위 10% | 3,000만 원 | 160만 원 | 400만 원 |
| 상위 25% | 1,200만 원 | 100만 원 | 200만 원 |
| 상위 50% | 500만 원 | 60만 원 | 100만 원 |
| 상위 75% | 180만 원 | 25만 원 | 30만 원 |
| 상위 90% | 60만 원 | 8만 원 | 0원 |
| 상위 100% | 20만 원 | 0원 | 0원 |

지원 성향 배율은 넉넉히 보태줌 ×1.3, 가능한 만큼 ×1, 자립 권유 ×0.45. 따라서 실제 시작 금액 범위는 9만~3억9,000만 원이고, 월 지원 최대 650만 원이다. 이 금액은 플레이어에게 주어진 돈이며 가족 전체 자산이 아니다.

월 지원은 대학 단계의 첫 달부터, 학기 지원은 입학 6개월 뒤부터 6개월마다 지급한다. 지급은 생활비·학비 차감 전에 처리하며 경제 모듈의 월 중복 방지와 저장을 사용한다. 미납으로 정산이 멈춘 경우 기존 납부·대출 선택을 먼저 해결한다. 졸업 뒤에는 새 지원이 없다. 지원금은 임금 인상률을 적용하지 않는다.

시작 배경 펼침에서 백분위·지원 성향·세 가지 금액·능력 보정을 볼 수 있다. 월 예산은 학기 지원을 6개월로 나눈 평균을 포함하고 실제 지급 주기도 표시한다. 월·학기 지원은 근로 연봉이 아닌 대학생 예상 수입으로 표시한다.

기존 저장에는 새 가족 지원이 생기지 않는다. 공개 배포는 이 변경에 포함되지 않는다. 분포·금액·성장 보정·피로 효과의 장기 균형 조정은 남아 있다.
