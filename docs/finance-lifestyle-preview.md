# 경제와 생활 설정

2026-10-13 사용자 요청 “다 구현하고 배포도 진행해”에 따른 확장. 금리·수익률·물가·급여 갱신·활동 시간과 효과는 변경 가능한 게임 시험 설정이다.

## 돈

- 현금·예금·투자 평가액을 분리한다. 모두 총자산에 포함되며 계좌 간 이동은 소득·지출이나 순자산 증가로 계산하지 않는다.
- 예금 연 명목 3%, 대출 연 명목 5%를 월별로 적용한다. 예금 이자는 예금에, 미상환 대출 이자는 부채에 더해진다. 원 미만 잔여분은 120000 분모의 정수로 저장하여 다음 달로 이월한다.
- 생활비·학비·개원 운영비는 월별 물가 누적을 반영한다(연 명목 3%). 기본 수입은 12개월마다 2% 갱신한다. 기존 저장은 도입한 달부터 계산하며 과거 이자를 소급 청구하지 않는다.
- 채권 중심·혼합·주식 중심은 서로 다른 투자 변동 폭을 가진다. 경기는 약 12개월 유지되고 그 안에서 매월 손익을 추첨한다. 새로고침·배속·다른 선택은 이미 계산한 수익을 다시 추첨하지 않는다. 실제 금융 상품이나 미래 수익 예측이 아니다.
- 매월 자동 상환·저축·투자 금액과 수동 예금/투자/인출/매도를 제공한다. 자동 이동은 미납이 없을 때 현금 여유 안에서만 처리한다. 생활비 부족액을 예금에서 납부하는 설정을 끌 수 있다. 투자금을 자동 매도하거나 새 대출을 몰래 만들지 않는다. 재학 중 자동 대출은 기존 명시 선택에만 따른다.
- 상단에는 순자산(총자산−부채−미납), 현재 연봉 또는 연 수입/매출 예상, 월 지출·잔여액을 표시한다. 예금 이자·투자 손익은 예상 연봉에 섞지 않는다. 월 예산에서 저축·투자·상환 뒤 현금 여유도 확인한다. 상세에는 정확한 원 단위 값을 보존한다.

## 생활

- 운동·모임·휴식·추가 공부·연구 모임·시간제 일을 동시에 켤 수 있다. 식생활은 절약·보통·여유 중 선택한다.
- 의무 일과를 제외한 여유 시간에서 주활동 6시간을 먼저 배정한다. 남은 시간보다 많은 활동을 새로 켤 수 없다. 수련·직업 전환이나 추가 업무로 시간이 줄면 화면에 중단된 활동을 표시한다.
- 게임 월의 1000 단위를 실제 켜 둔 기간만큼 누적한다. 월말 직전 잠깐 켠 활동에 한 달 전체 보상을 주지 않는다. 비용을 감당하지 못한 유료 활동은 비용과 효과를 모두 생략하고 기록한다.
- 지속 효과는 네 표시 스탯, 준비 경험, 피로와 생활 기록에 연결된다. 기본 성과 누적/하락은 `life-dynamics.ts`와 함께 작동한다.
