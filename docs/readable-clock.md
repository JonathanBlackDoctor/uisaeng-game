# 읽을 수 있는 1배속

2026-10-14 사용자 피드백: “1배속인데도 너무 빨라”. 현재 기본 분량에서 졸업 이후 한 달 163ms, 1년 1.956초로 지나가는 문제를 조정한다.

조정 가능한 시험값으로 기본(short)은 대학 한 달 3.9초, 이후 2초로, 길게(standard)는 대학 7.8초, 이후 4초로 늦췄다. 졸업 이후 1년은 기본 24초, 길게 48초다. 선택을 읽는 시간은 제외한 값이며 실제 사람 플레이 시간 측정은 아니다. 기존 70% 진행 시간 목표보다 이번 속도 피드백을 우선한다.

현재 pacingVersion=1인 진행 중 저장에도 적용한다. 저장된 나이·월·선택·배속·분량 식별자는 유지한다. 이전 월의 소수 진행 잔여값은 새 월 길이보다 작으므로 그대로 읽을 수 있고, 처음 이어지는 진행의 차이는 게임 내 0.001개월 미만이다. pacingVersion이 없는 초기 구형 저장과 별도 복무 시계는 이번 변경 대상이 아니다.

월별 능력·생활·돈 계산, 사건 구성, 1/2/4/8/16배속, 중요 선택 정지 및 다음 선택 건너뛰기는 유지한다. 능력치 100 초과 허용은 별도 설계 제안이며 구현하지 않는다.

이번 변경은 로컬 작업이다. 공개 배포와 실제 브라우저 플레이 검증은 별도 상태로 기록한다.

검증: 새 월 진행·기존 소수 월 저장 복원 4개 통과. 분량·서사·배속·개원 30개 통과. 전체 타입 검사는 별도 직업 측정 파일 `tests/profession-quality.test.ts`의 Node 타입 미설정으로 실패했으며, 해당 파일만 제외한 모든 게임 소스·나머지 검사 타입 검증과 Vite 번들 생성은 통과했다. 진로 완주 41개는 느려진 실제 진행에 맞춰 제한 시간을 늘리고 검사 사이 작업자 응답을 허용한 뒤 모두 통과했다. 관련 고유 검사 총 75개 통과. 최초 제한 시간 실패 2개 및 작업자 응답 시간 초과는 성공으로 취급하지 않는다.
