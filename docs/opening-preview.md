## 입학 통지서 구현 — 2026-10-14

사용자가 입학 통지서안을 선택하고 구체화한 계획대로 구현을 지시했다. 회백색 종이, 얕은 그림자·접힌 자국, 명조체 제목과 녹색 선으로 첫 화면을 구성했다. `통지서 열기`를 누르면 0.6초 펼침 효과와 함께 실제 생성된 성장 배경·가족 지원·현금·네 스탯이 같은 종이 안에 나타난다. 이름·학교명·학번을 임의로 만들지 않는다.

`첫 학기 시작`은 기존 CAS 저장에 성공한 뒤 0.55초 동안 종이가 위로 빠지고 캠퍼스 일러스트가 드러나는 전환을 거쳐 실제 플레이를 시작한다. 전환 중에는 입력을 잠그고 게임 시간을 진행하지 않는다. 동작 줄이기 설정에서는 애니메이션과 전환 대기를 생략한다. 초안은 저장 전까지 메모리에만 유지하며 취소/새로고침 시 기존 기록이 보존된다. 캠퍼스는 별도 코드 SVG `AdmissionCampus.tsx`로 표현하여 현재 플레이 장면과 구분했다.

변경: `Opening.tsx`, `opening.css`, `AdmissionCampus.tsx`, `main.tsx`. 시간 조작 회귀의 전체 생애 보조 함수는 최신 엔진의 자연 종료도 정상 도착으로 판정하도록 갱신했다. 예전 단계 종료 팝업의 필수 존재 검사는 완료 상태·마지막 단계·빈 pending 검증으로 교체했다. 게임 규칙 변경은 없다.

검증: 저장/시간/업데이트 27개 통과, 앱 소스 범위 TypeScript 검사와 production 빌드 통과. 전체 프로젝트 타입 검사는 동시에 수정 중이던 별도 테스트 파일의 오류가 있어 성공으로 기록하지 않는다. 390×844/320×740/1024×768에서 시작 버튼이 첫 화면에 보이고 가로 넘침 없음. 고정 production 빌드에서 펼침 중 값 유지, 전환 클래스와 캠퍼스 존재, 시작 전후 스탯·현금 일치, 기존 기록 복원, 새 게임 취소·초안 새로고침 보존 및 console 경고/오류 0을 확인했다. 실제 기기·동작 줄이기 설정의 브라우저 실행은 미검수다.

증거: `.orchestrator/ui-qa/admission-letter/qa.json` 및 PNG. 고정 빌드 `.orchestrator/admission-letter-build`, 검수 주소 `http://localhost:5292/game/`. 공개 배포하지 않았다. 아래는 이전 오프닝 검증 기록이다.

2026-10-13 사용자 요청: “게임의 오프닝이 좀 애매해. 시작하는 느낌이 부족한 것 같아.”

첫 화면을 플레이 대시보드에서 분리했다. `20세, 의대에 입학했다.`라는 타이틀과 캠퍼스 장면을 보여주고, `입학하기`를 누르면 이번 인물의 실제 성장 배경·가족 지원 성향·보유 현금·건강/행복/지식/관계를 확인한다. `첫 학기 시작`을 누르면 해당 인물을 그대로 저장하고 기존 시간 조작의 재생 상태로 진입한다. 새 확률·스탯·경제 규칙은 추가하지 않았다.

입학 배경은 메모리의 초안이다. 확인 중에는 시간이 흐르지 않고, 시작하기 전에는 기존 저장을 덮어쓰지 않는다. 돌아가기 또는 새로고침하면 초안을 취소한다. 시작 시 기존 CAS 저장 검사를 사용하며 저장 실패 시 플레이에 진입하지 않는다. 이미 저장된 게임은 기존 화면으로 바로 복원한다. 짧은 등장 효과는 동작 줄이기 설정에서 생략한다.

변경 파일: `game/src/Opening.tsx`, `game/src/opening.css`, `game/src/main.tsx`. 기존 로고와 LifeScene을 재사용했다. 동시에 진행된 다른 작업의 버전 표시·문구 변경은 유지했다.

검증: TypeScript 검사 및 별도 production 빌드 성공. 저장·시간 조작·업데이트 관련 기존 테스트 26개 통과. 실제 브라우저에서 390×844 및 1024×768의 타이틀/입학 배경, 배경 확인 중 상태 유지, 시작 전후 능력치·돈 일치, 새 게임 취소/초안 새로고침 시 기존 저장 보존, 첫 선택 저장 복원을 확인했다. 가로 넘침 및 console 경고/오류 없음. 증거: `.orchestrator/ui-qa/opening/qa.json` 및 PNG. 실제 모바일 기기 검수는 하지 않았다.

검수 빌드: `.orchestrator/opening-build`. 공개 배포는 하지 않았다. 이 변경은 오프닝 개선이며 게임 전체 완성이나 기존 미정 규칙의 확정이 아니다.

## 약 5초 오프닝 연출 — 2026-10-15

사용자가 제안안을 승인하고 약 5초로 구현하도록 요청했다. 자동 연출은 봉투 도착 700ms, 덮개 열기·종이 추출·두 면 펼침 2100ms, 캠퍼스 확대·캐릭터 걸음·첫 학기 표시 2200ms다. 합격증을 읽는 시간과 저장 I/O는 5초에 포함하지 않는다. 합격증의 실제 배정 대학·이름·입학 나이·입학 경로·배경·현금·능력치는 유지한다. 능력치 설명은 펼쳐볼 수 있으며, 초안에서는 게임 시간이 흐르지 않는다.

소리는 첫 사용자 입력 뒤 Web Audio로 종이·화음·바람·발소리를 합성한다. 외부 음원 요청은 없다. 소리 끄기, 펼침/진입 건너뛰기, prefers-reduced-motion 대기 생략을 제공한다. 시작 저장에 성공한 뒤 진입 연출을 시작하고 헤더·합격증·푸터 입력을 잠근다. 진입 완료·건너뛰기·동작 줄이기 변경은 같은 완료 경로로 처리한다. 기존 새 게임 확인의 '입학 배경 보기'는 합격증으로 바로 이동하는 기존 흐름을 유지한다.

변경: Opening.tsx, opening.css, AdmissionCampus.tsx, main.tsx, opening-motion.ts, opening-audio.ts. 회귀: opening-motion.test.ts. 독립 화면 검수: tests/browser/opening.html 및 opening.tsx (저장소를 쓰지 않으며 캠퍼스 마지막 프레임을 유지할 수 있다).

검증: 프로젝트 TypeScript 검사와 production 빌드 통과. 저장 9·업데이트 11·입학 2·시간 조작 7·전환 4, 총 33개 관련 테스트 통과. 시간 조작의 전체 생애 테스트는 최초 기본 5초 제한으로 시간 초과, 제한을 20초로 늘린 실행에서 5.5초에 통과했다. 일반 동작·즉시 건너뛰기·초기 reduced motion·진행 중 reduced motion 전환 및 타이머 정리 회귀를 확인했다.

실제 브라우저: PC 1280×720, 모바일 390×844/320×740에서 확인. 모바일 봉투·합격증 가로 넘침 없음. 실제 시작 버튼부터 플레이 마운트까지 2367ms(저장 및 브라우저 조작 시간 포함), 진입 중 게임 화면 미마운트 및 입력 잠금 확인. 시작 전후 스탯 59/50/41/38과 현금 356만 원 일치, 시작 직후 21세 0개월 확인. 최종 production 빌드에서 정상 펼침·진입 건너뛰기·초안 새로고침 시 기존 인물 복원, console warn/error 0 확인. 실제 휴대폰·실제 OS 동작 줄이기·스피커 청감 검수는 미실행이며, reduced motion 완료 동작은 자동 테스트로 검증했다.

고정 검수 빌드: .orchestrator/opening-cinematic-build, 로컬 주소 http://127.0.0.1:5294/game/. 화면·관찰값·소스 해시: .orchestrator/ui-qa/opening-cinematic/. campus-*-fixture.png는 실제 Opening 컴포넌트의 진입 마지막 구도를 유지한 검수 화면으로 하단 검수 조작 버튼이 포함된다. envelope-desktop-production.png는 최종 production 첫 화면이다. 공개 배포는 수행하지 않았다.

### 새 게임 재진입과 첫 화면 단순화 — 2026-10-15

후속 사용자 요청에 따라 새 게임 확인의 '새 게임 시작'은 새 인물을 즉시 생성하지 않고 봉투 화면부터 보여준다. 클릭하면 초안을 생성하고 기존 펼침 연출을 재생한다. 봉투 화면에서는 로고·푸터·봉투 제목·부제·열기 버튼 문구를 숨기고 '도착한 편지 한 통'만 남긴다. 소리는 글자 없는 아이콘으로 조절한다. 화면 전체를 실제 button으로 구성하여 봉투 바깥 클릭·터치·Enter/Space로 열 수 있다. Escape 또는 합격증의 돌아가기는 기존 게임으로 돌아간다.

openingRequested 상태로 봉투 대기 중 기존 시계와 결과 안내를 중지하며, 기존 저장은 첫 학기 시작 전까지 보존한다. PC 1280×720과 모바일 320×740에서 화면 전체 클릭 영역과 가로 넘침 없음을 확인했다. 실제 새 게임→봉투→빈 공간 클릭→펼침, Enter 열기, 취소 복귀와 대기 중 기존 시간 보존(21세 1개월) 확인. 관련 저장·입학·전환 테스트 15개, 프로젝트 타입 검사, 최종 빌드 통과. 최종 자산 index-Bmb6WZIg.css / index-CykGEjFO.js. 기존 5294 미리보기를 갱신했다. 증거: minimal-envelope-desktop.png, minimal-envelope-mobile.png 및 minimal-source-hashes.json. 이전 33개 검증은 이전 변경의 기록이며 이번 수정에서 재실행한 테스트 수는 15개다.
