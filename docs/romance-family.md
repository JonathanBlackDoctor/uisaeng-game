# 연애·결혼·육아 구현 현황

2026-10-12 사용자 승인: “승인. 과팅, 소개팅, cc 모두 구현.”
범위 승인은 `design/decisions.json`의 `romance-family-scope-v1`에 기록했다.

## 플레이 가능한 범위

- 과팅: 다른 학교 학생들과의 모임 → 별도 만남 → 서로 동의한 교제.
- 소개팅: 친구의 주선으로 다른 분야의 사람과 만남 → 재회 → 교제.
- CC: 같은 캠퍼스 동아리 인연 → 교제 → 관계 공개·사생활 합의.
- 수련: 약속과 근무 일정 조율, 갈등 대화 또는 이별 → 결혼 또는 교제 유지 → 자녀 계획.
- 경력: 자녀가 있으면 돌봄 분담 또는 외부 지원 → 성장한 아이와 대화. 자녀가 없으면 두 사람의 진로 조율. 혼자라면 친구·동료 또는 자신의 생활을 가꾸는 사건.
- 은퇴: 선택한 관계와 가족 상태가 생애 기록 및 회고 보관함에 남는다.

기존 일상 사건 4개 뒤에 상태에 맞는 가족 사건을 연결한다. 가족 사건 정의는 14개이며 한 회차에 모두 등장하지 않는다. 표시 스탯은 건강·행복·지식·관계 그대로이고, 배우자·자녀·돌봄 방식은 별도의 생활 기록이다. 인물의 성별이나 성적 지향을 고정하지 않는다.

## 사실·가정·조정값

- 사건과 등장인물은 창작이다. 관계 판정과 효과 산정에 외부 통계나 개인 확률을 사용하지 않는다. 별도로 표시되는 배경 근거는 사건의 인물·전개·수치를 사실로 만들지 않는다.
- 이번 미리보기의 게임 가정: 한 회차에 한 인연, 자녀는 한 성장 경로, 자녀를 맞이하는 과정과 여러 해의 성장을 사건으로 압축한다. 연애를 시작한 경우 결혼하지 않고 자녀를 키우는 경로도 가능하다.
- 효과 수치와 4단계 사건 간격은 시험값이다. 연애·결혼·자녀 여부 자체에 성공 판정이나 강제 조건을 두지 않는다. 세부 균형과 정식 시간 체계는 미확정이다.

## 저장과 남은 범위

새 이야기는 `family-preview-v1`로 시작한다. 기존 `fixture-v1` 저장과 회고는 변환하지 않고 원래 4장면으로 이어간다. 기존 진행을 끝내거나 백업한 뒤 새 이야기를 시작하면 새 기능을 이용할 수 있다. 가족 사건 도중에도 선택과 상태가 함께 저장된다.

재회·새 연인·재혼·다자녀, 임신·출산의 개별 과정, 세부 경제·주거 시스템은 이번 구현에 없다. 정식 26개 전공 및 전체 게임, 30~45분 플레이 시간 완성을 의미하지 않는다.

## 검증 기록

2026-10-12: 전체 게임 테스트 22개 통과(가족 기능 6개 포함), TypeScript 검사 및 Vite 빌드 통과. 과팅·소개팅·CC별 결혼·육아·회고의 저장/재개, 모든 제공 분기의 유효 상태와 종료, 중복·오래된 선택 거부, 손상 저장 거부를 검증했다. 실제 데스크톱 브라우저에서 만남 선택지·CC 전용 사건·새로고침 후 교제 상태 유지도 확인했다. 모바일 화면과 실제 30~45분 플레이는 검증하지 않았다.
