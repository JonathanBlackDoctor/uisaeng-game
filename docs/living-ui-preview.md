# 생활 장면 중심 UI 미리보기

2026-10-12, HQ002. 사용자 승인 `homage-living-ui-and-orchestration-v1`의 로컬 구현 결과다. 정식 게임 전체 완성을 의미하지 않는다.

## 구현

- 고정 사이드바·캠퍼스 배치를 상단 내비게이션, 나이·연간 진행률·정지·배속, 중앙 생활 장면으로 교체했다.
- 대학·수련·의사 일상·은퇴 장면, 계절, 생활 초점, 시작 시드에 따른 외모, 현재 연인·배우자·자녀를 연결했다. 미해결 선택 또는 일시정지 중에는 장면의 지속 모션도 멈춘다.
- PC는 능력치·인물·최근 기록을 장면 옆에, 모바일은 네 능력치를 시간 바로 아래에 배치한다. 생애 지도는 실제 기록에 적힌 나이에만 사건을 연결한다.
- 중요한 선택은 접근성 dialog로 표시한다. 접기/Escape는 사건을 해결하지 않으며 시간이 계속 멈춘다. 다시 펼치기, 숫자 선택, 700ms 오입력 방지, 중복 선택 방지를 제공한다.
- 근거가 있는 사건만 출처 링크가 달린 한 문장을 표시한다. 제목·설명·펼침 영역은 없다. 서로 알아가는 상대와 연인·배우자를 구분한다. 이전 저장에 없는 나이·연락망 수를 임의로 표시하지 않는다.
- 엔진·저장 형식과 기존 연구·가족·근거 구현을 보존했다. 실제 서비스는 기존 포트 4317의 game/dist를 사용한다.
