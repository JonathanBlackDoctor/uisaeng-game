# 전공·기관·선배 후속 경로 시험 구현

2026-10-13 HQ010 구현·HQ011 통합 검수. 사용자 승인 `next-development-specialty-institution-activity-depth-v1` 적용. 별도 사용자 작업의 성과 누적·재산 표시도 함께 검수했다.

- 26개 전공마다 수련 사건과 직업 사건 각 1개, 각 3선택: 총 52사건·156선택. 유료 학습 52개, 무료 대안 104개. 선택에 따라 숙련·안전관리 경험, 네 스탯, 일회성 비용이 다르며 3개월 뒤 후속 기록을 남긴다. 실제 급여 순위는 만들지 않았다.
- 전공의 숙련·안전관리 경험을 쌓으면 진료 후 기록 검토 사건에서 기존 점검 기록을 활용하는 선택이 열린다. 행복 손실을 줄이고 기본 업무 일정으로 돌아온다.
- 서울대·아산은 확인된 2026년 지원 안내에 따른 서류 확인 단계와 병원 재선택을 제공한다. 이는 해당 연도 공고를 읽는 가상 지원 장면이며 실제 자격 검증이나 합격 보장이 아니다. 다른 3기관의 지원 절차는 근거 공백이다. 합격 공식은 기존 공통 provisional 설정을 유지한다.
- 병원별 교육 안내를 별도 수련 기회로 연결한다. 서울대 기록평가/연구질문, 아산 시뮬레이션/검토, 삼성 진료/연구/소통 모임, 세브란스 보완계획/면담, 서울성모 모형술기/문헌검색. 선택 후 다른 숙련·안전관리 경험과 3개월 뒤 연구/임상/관계 경험으로 연결한다. 실제 교육의 참여·성과·보수는 보장하지 않는다.
- 삼성은 **2020 자료이며 현행 운영 미확인**. 세브란스는 **2026 발표 계획, 인턴과 지정 7개 전문과목 범위**이며 다른 과는 출처 없는 공통 가상 지도검토를 쓴다. 각 사건에는 확인된 근거가 있을 때만 링크가 달린 한 문장을 표시한다. 조사 근거·발췌 해시는 `design/institution-depth-research-v1.json`과 그 capture에 보존했다.
- 농구·밴드·봉사·연구·사진·등산의 특정 선배와 함께 마친 프로젝트·만남 기록이 있으면 수련 중 재회 기회가 열린다. 같은 전공의 수련 발표 또는 다른 전공 간 토론, 친구로 만나기, 쉬기를 고른다. 협업은 3개월 뒤 발표와 연구 경험으로 연결된다.
- 업무 일정은 기본/추가 업무/유료교육 중 선택하고 경력 패널에서 바꾼다. 추가 업무는 봉직 월60만원, 개원 월매출90만원·운영비30만원을 추가하며 석 달마다 건강-2·행복-1. 유료 교육은 월12만원, 숙련·안전관리 경험과 석 달마다 건강+1. 잔액 부족 시 교육을 중단하고 무료 검토로 전환한다. 모두 수정 가능한 가상 수치이며 실제 병원 급여·위험 자료가 아니다.
- 공통 216/300개월 고정 사망·분쟁을 신규 경로에서 제거했다. 전공·시드·월에 따른 가상 사건 덱으로 때가 달라지고, 임상/수술 맥락은 환자 사망이나 기록 검토, 진단/지역 맥락은 기록 검토 장면이다. 보고 건수나 현실 개인 위험률을 사용하지 않았다. 사망은 플레이어 실수의 인과 결과로 계산하지 않는다.
- `depth`가 없는 기존 저장은 현재 월부터 업그레이드하며 과거 일괄 정산은 하지 않는다. 기존에 대기 중인 사망·분쟁/지원 사건은 구문구로도 읽고 한 번만 처리한다. 월별 처리 번호와 결정 기록으로 중복 비용·후속 보상을 막는다.
