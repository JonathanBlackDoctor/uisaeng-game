# 기본 옵션의 스토리 선택 추가 감축

2026-10-15 사용자 지시: “너무 적게 줄였다. 스토리 관련도 줄여도 돼.” 이전의 전체 스토리 장면 보존 제한을 이번 범위에서 대체한다.

## 적용

- 새 게임의 기본 길이는 journey version 3으로 시작한다. 기존 진행 저장과 길게 옵션은 기존 장면 순서를 유지한다.
- 대학 필수 보조 장면은 팀·여름·실습을 생략하고 마지막 장면만 남긴다(4→1). 동아리 프로젝트와 후속은 유지한다.
- 전공별 경력 장면은 수련 첫 장면과 경력 마지막 장면을 남긴다(4→2). 마지막 장면은 실제로 경험한 이전 장면을 회고한다.
- 학술 경로의 연구·교육·진료 운영 선택은 직급마다 한 번의 통합 선택으로 묶는다(3→1). 주도·협력·휴식·진로 이탈 선택을 제공하고, 주도·협력만 세 영역의 실적을 준다. 승진 시점과 심사 조건을 유지한다.
- 기관·수련 환경·업무량의 별도 질문, 능력 단독 사건, 독립 임상 사례와 추가 보조 이야기 일부를 생략한다. 연결 이야기와 주요 진로·자격·승진·이탈·결말은 유지한다.
- 기존 반복 선택 상한과 로그 압축은 유지한다. 시계는 기본 대학/이후 3900/2000ms로 유지한다. 통합 선택의 보상 수치는 변경 가능한 시험 설정이다.

## 고정본 검증

2026-10-15 통합 후속: 치과·한의과·간호의 별도 직업 장면에도 새 기본 게임의 축소 기준을 연결했다. 직업 보조 장면 상한은 대학 1·수련/초기 적응 1·경력 2·은퇴 1로 조정했다. 면허·전문자격·직군별 진로·전환·학술 승진은 유지한다. journey version 2의 기존 기본 저장과 길게 옵션은 이전 상한을 유지한다. 세 직군의 신구 기본 생애 비교·필수 선택·후속 기록·회고 저장 복구 검사 3개가 통과했다. 최종 통합본 검증 결과는 별도 릴리스 기록에 남긴다.

증거: `.orchestrator/ui-qa/condensed-story-20261015/verification.json`, 같은 폴더의 `measurement.json`, 재현 도구 `scripts/measure-condensed-story.mjs`.

최종 고정본의 관련 8개 파일 174개 검사 통과. 소스와 신규 검사 타입 검사 및 Vite 빌드 통과(큰 번들 경고 있음). 전체 타입 검사는 다른 변경으로 추가된 Opening의 onSkipEnter 인자를 기존 검사 호출부가 누락하여 실패했다. 실제 브라우저 플레이와 이번 변경의 공개 배포는 수행하지 않았다.

같은 소스·시드·선택 정책에서 새 스토리 압축만 끄고 켠 비교다. 여섯 경로 모두 완주했고 연결 이야기의 선택 키, 후속 완료, 자동 진행 시간이 유지됐다. 중간 장면은 의도적으로 삭제했으므로 전체 서사 원문 보존을 주장하지 않는다.
