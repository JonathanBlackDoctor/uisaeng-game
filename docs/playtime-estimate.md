# 플레이 시간 추정

2026-10-13 HQ007. **실제 사람 플레이 측정은 아직 완료하지 않았다.** 아래 수치는 현재 엔진과 선택문 분량으로 계산한 시나리오 추정이다. 자동 UI 완주 시간이나 `다음 선택까지`의 합성 진행 시간을 사람의 플레이 시간으로 사용하지 않았다.

미수련·연구, 내과·봉직, 내과·개원을 시드 9·42·103으로 각각 진행했다. 9개 경로 모두 회고까지 완료됐다. 1배속 엔진의 누적 활성시간은 경로마다 대학 1,440초, 이후 612초로 같았다. 이는 진행시간 34.2분과 대학 비중70.2%이며, 선택을 읽는 시간은 별도다.

선택마다 제목·본문·모든 선택지·설명을 한 번 읽고 판단에 8초를 쓴다고 가정했다. 공백을 제외한 분당180·300·450자를 읽는 세 조건은 관측한 읽기 속도가 아닌 계산 입력값이다. 로그 읽기, 장면 살펴보기, 직접 일시정지, 자리 비움, 도구 대기는 제외했다. 전공 선택의 27개 선택지를 모두 읽는 가정도 포함하므로 실제로 일부만 훑는 사람에게 그대로 적용할 수 없다.

범위는 9개 경로와 3개 읽기 조건의 최솟값·최댓값이다. 선택 정책은 동아리 미가입, 미수련/내과, 연구/봉직/개원, 초대 거절, 결혼 유지 또는 독신 선택이다. 경로별 선택 수·문자 수·활성시간·소스 해시와 계산 결과는 `.orchestrator/ui-qa/hq007/playtime-estimate.json`, 재현 코드는 같은 폴더의 `estimate-playtime.mjs`에 있다. 프로젝트 루트에서 `node .orchestrator/ui-qa/hq007/estimate-playtime.mjs`로 실행한다. 새 소스에는 기존 수치를 재인증하지 않는다.

대표 사람 검증에서는 시작·졸업·회고 시각, 배속, 선택 읽기·판단, 기록·장면 탐색, 일시정지·자리 비움을 구분해 기록해야 한다. 대학 비중50% 달성이나 원작과 같은 시간 체감은 이 추정만으로 확정하지 않는다. 다음 선택까지를 사용하는 플레이는 진행 대기 시간이 사라지므로 별도 조건으로 측정한다.
