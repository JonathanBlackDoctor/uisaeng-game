# 의·치·한·간 직업 확장

2026-10-14 구현, 2026-10-15 비교 검수와 개선. 새 게임의 입학 통지서에서 의대·치대·한의대·간호대를 고른다. 기존 저장에 직군 필드가 없으면 기존 의과 경로로 해석한다. 진행 중 직군 변경은 제공하지 않는다. 최신 비교 결과와 실제 플레이 범위는 [직군 확장 비교 검수](profession-quality-review.md)에 있다.

## 구현 범위

| 직군 | 분야 | 직업 장면 | 주요 경로 |
|---|---:|---:|---|
| 치과 | 11 | 67 | 국가시험, 일반진료·전문의 수련·연구, 봉직·개원, 연구·교육 경력, 은퇴 |
| 한의과 | 8 | 58 | 국가시험, 일반진료·전문의 수련·연구, 봉직·개원, 연구·교육 경력, 은퇴 |
| 간호 | 19 | 91 | 국가시험, 취업·연구, 부서 이동과 적응, 근무 형태, 13개 전문자격, 연구·교육 경력, 은퇴 |

분야별 실습·업무·개선 장면과 선택 뒤 후속 기록을 제공한다. 모든 장면이 한 번의 플레이에 나타나지는 않는다. 의과의 공통 생활·관계·가족·경제·병역·재무 사건과 연속 시간 진행을 함께 사용한다. 직군별 도감, 장비 그림, 자격 기록, 회고에도 연결했다. 간호 업무 분야와 전문간호사 자격은 별개로 기록한다.

추가 직군의 학교·수련 흐름은 `profession-runtime.ts`가 처리하며 기존 의과 전용 대학·분과 경로는 의과에 유지한다. 기존 26개 의과 목록과 50개 주요 사건 목록은 유지하고, 전체 목록을 별도로 제공한다.

## 사실과 조정값

근거와 원문 해시는 [직업 확장 근거](professions-evidence.md)와 [근거 목록](../design/profession-evidence-v1.json)에 있다. `research/` 원본은 수정하지 않았다. 국가시험·수련·전문간호사 교육 화면에 관련 공식 출처 한 문장을 연결했다.

치과 기본 수련은 48개월, 통합치의학과는 36개월, 한의과 기본 수련은 48개월로 구분한다. 전문간호사 교육은 해당 분야 실무 36개월 이후 최소 24개월 교육과 별도 평가로 구현했다. 실제 인정기관·교육 전 10년 경력 범위·예외 심사는 게임에서 단순화한다.

대학 72/48개월은 선택한 게임 경로다. 간호 적응 12개월, 급여·등록금·교대 수당·교육비, 재응시 간격·성적 기준·승진 기준·사건 확률은 변경 가능한 시험 설정이며 실제 통계나 정식 규칙 승인으로 간주하지 않는다. `professions.ts`의 규칙 버전은 `professions-provisional-1`이다.

## 검증과 제한

신규 경로 테스트는 38개 분야 생애 진행, 13개 간호 전문자격, 일반진료·연구·개원·부서 이동, 남녀 병역 분기, 실제 IndexedDB 저장·재개·충돌·회고 보관을 확인한다. 각 단계에서 저장 유효성을 검사한다. 수련·교육 기록 없는 자격이나 다른 직군 분야를 주입한 저장은 거부한다. 도감과 SVG는 서버 렌더링 및 로컬 이미지 렌더링으로 확인했다.

최초 구현의 실행 결과는 `.orchestrator/professions-v1/final-validation.json`과 같은 디렉터리의 테스트 보고서에 기록했다. 이후 품질 개선의 결과는 `.orchestrator/profession-quality-v1/final-validation.json`에 별도로 보존한다. 과거 성공을 변경된 소스의 검증으로 취급하지 않는다.

통합 실행은 656개 중 655개 통과했다. 남은 1개는 과목 목록을 기존 의과 26개로 가정한 테스트였으며 전체 64개 목록으로 수정한 뒤 해당 파일 8개가 모두 통과했다. 마지막 결과 문구 변경의 통합·공유 테스트 16개도 통과했다. 따라서 개별 최신 결과 기준 656개에 미해결 실패가 없으며, 두 번째 전체 실행을 했다고 기록하지 않는다. 별도 Node 모듈 테스트 37개, 최종 TypeScript 검사와 Vite 빌드도 통과했다. 주요 JS 묶음은 약 931 kB(압축 약 298 kB)로 Vite 권고 크기 경고가 있다.

최초 구현에서는 브라우저 접근 차단 때문에 실제 조작 검증이 미실행이었다. 후속 요청에서는 현재 제공된 브라우저로 기존 로컬 서버에 접근할 수 있었고, 치과·한의과·간호의 대표 생애를 실제 UI로 회고까지 진행했다. PC와 320/390px 모바일 화면, 긴 선택지, 키보드, 애니메이션, 새로고침과 도감·회고 복구를 확인했다. 1배속 전체 실시간 대기와 실제 휴대폰 검증은 별개이며, 자동 생애 실행을 GUI 플레이로 표현하지 않았다. 후속 관련 검사 최신 개별 결과 160개에 미해결 실패가 없고 타입 검사와 빌드도 통과했다. 공개 배포는 하지 않았다.

## 작업 운영과 비용

이번 작업은 현재 채팅 하나에서 부모 통합 담당과 최대 3개 보조 에이전트를 사용했다. 콘텐츠·화면은 gpt-6.1-sol/medium, 경로·저장 검수는 gpt-6.1-sol/high로 나누고, 공통 엔진과 타입은 부모가 맡았다. 완료한 에이전트에 추가 작업을 반복 배정하지 않는다. 별도 채팅·상시 감시 AI·유료 구매·사용량 초기화는 추가하지 않았다.

앞서 제시한 55–94시간(여유 포함 70–120시간)은 전체 제작·검수 공수의 사전 추정이다. 토큰·크레딧 시나리오 역시 실측 청구액이 아니다. 계정 사용량은 다른 작업과 공유하므로 이번 기능의 정확한 비용으로 환산할 수 없다. 대표 GUI 경로는 확인했으며, 실제 휴대폰과 여러 선택 전략의 밸런스 검수는 남아 있다.
