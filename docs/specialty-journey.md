# 전공 이야기·분과 수련·교수 진로

2026-10-14. 사용자 요청: 전공마다 다른 한 판으로 느껴질 만큼 구체적인 이야기를 늘리고, 없는 과·분과전문의·교수 경로를 구현한다. 이 문서는 구현 범위와 검수 기록이며 정식 수련·임용 규칙의 승인 기록이 아니다.

## 콘텐츠

- 기존 임상 전공 26개를 모두 유지하고 과마다 수련 2장·전문의 이후 2장, 총 104개의 고유 장면을 추가했다. 기존 `specialty-depth.ts`와 `specialty-chapters.ts` 사건은 보존했다.
- 앞 장에서 직접 맡기·협업·휴식 중 무엇을 골랐는지 다음 본문에 남는다. 직접 맡거나 협업한 경우 이전 경험을 이번 상황에 맞춰 쓰는 선택이 열린다. 숙련·안전관리와 건강·행복·지식·관계에 서로 다른 결과를 주며 3개월 뒤 후속 기록을 남긴다.
- 내과의 반복 입원과 퇴원 돌봄, 외과의 수술 보조와 회복, 소아청소년과의 학교생활과 성인 진료 전환, 정형외과의 선수 복귀와 작업 동작, 병리과의 작은 검체와 판독 차이, 응급의학과의 구급대 인계와 병상 대기 등 과별 상황을 별도로 작성했다.
- 26개 과 아래 분과·세부 분야 143개를 선택할 수 있다. 각 분야에는 서로 다른 사례 질문이 있으며 전임의 사례 추적, 연구·공동 토론, 수료 심사로 연결된다. 두 수련 단계의 진행 틀은 공통이고 사례 맥락은 분야별이다. 143개 모두를 별도의 공인 자격이라고 부르지 않는다.
- 기존 선택지에 없던 해부학·생리학·생화학·약리학·미생물학·기생충학·면역학·법의학·의학교육학·의료정보학, 10개 기초·연구 교실을 추가했다. 임상 전문과목과 구분해 연구 경로에서 선택한다. 수련에 지원하지 않았거나 탈락 후 연구로 전환한 경우에도 가능하다.

## 실행 경로

전문의 → 전임의 → 분과·세부 수련 완료 → 임상강사 → 조교수 → 부교수 → 정교수.

기초·연구 교실 → 연구교원 → 조교수 → 부교수 → 정교수.

전임의 수련에서는 직접 사례·연구를 맡거나 공동 작업을 선택한다. 성과가 부족하면 보완하고 다시 심사하며, 중단 후 봉직 진료로 돌아갈 수 있다. 개원 중 추가 수련을 고르면 설명된 대로 병원 근무로 전환한다. 이미 지출한 개원비를 환불하거나 임의의 보상을 지급하지 않는다.

교수 단계마다 연구·교육·팀 운영 사건이 따로 열린다. 연구 자료 누락, 기관 간 공동연구, 후배의 독립 연구, 학생 수업, 평가와 지도 역할, 팀의 업무 규모와 인계를 다룬다. 연구·교육·팀 기여 요건을 모두 채워야 다음 임용·승진 선택이 열린다. 휴식한 경우 부족한 항목을 보완할 수 있고, 대학 밖으로 옮기는 선택도 있다. 승진마다 새 단계의 실적을 모으며 이전 실적으로 연속 승진할 수 없다.

정교수 이후에는 후배 연구 지원·교육·지역 협력 중 맡을 일을 정한다. 최종 진로와 선택은 은퇴 회고에 남는다. 진로 패널의 현재 직함, 세부 분야, 자격·수련 상태와 다음 심사 요건은 실제 결정 기록에서 계산한다.

## 게임 설정과 제도 정보의 구분

규칙 버전은 `specialty-journey-provisional-1`. 사건 간격 4개월, 전임의 최소 수련 18개월, 단계별 임용·승진 24/48/60개월, 보완 심사 간격 6개월 및 성과 기준은 모두 변경 가능한 게임 조정값이다. 실제 대학 임용 기준, 학회 자격 요건, 급여, 임상 결과 또는 사고 확률을 재현한 값이 아니다. 기존 경제 모델을 사용하며 별도 교수 급여표는 만들지 않았다.

내과 분과 수련 완료에는 게임상 ‘분과전문의’를 표시한다. 다른 분야는 ‘세부 수련 완료’로 구분한다. 분과·세부 전문 제도 분류는 [대한의학회 안내](https://kams.or.kr/business/judge/sub1/sub3.php)를 참고했지만 해당 페이지 본문은 403으로 열리지 않았으며 검색에 노출된 분류만 확인했다. 각 분야의 현행 인증 여부를 전부 확인한 것으로 간주하지 않는다. [경상국립대학교 내과학교실 소개](https://www.gnu.ac.kr/medicine/cm/cntnts/cntntsView.do?cntntsId=1384&mi=1687)는 내과의 분과별 업무 맥락 참고에 사용했다. 게임 사건은 가상 창작이며 실제 환자 사례나 진료 지침이 아니다.

## 저장과 검수

새 상태는 선택별 월·선택 ID·후속 처리 여부만 저장한다. 분과 수료·교수 직함·실적은 기록으로 계산한다. 저장을 읽을 때 같은 진행 조건으로 기록을 재생해 건너뛴 수료·승진, 다른 과의 분야, 미래 기록, 손상된 데이터를 거부한다. 옛 저장에 새 상태가 없으면 현재 월부터 시작하며 과거의 수련을 소급 보상하지 않는다. 재지원으로 수련이 늦어진 경우, 수련 종료 월의 선택, 미수련 연구자, 연구 진로 유지도 포함한다.

전용 검사 47개 통과. 26과의 4장·분과 수료·정교수·회고, 143개 분야의 사례 질문, 10개 연구 교실, 이전 선택에 따른 문구·선택 해금, 수련·승진 보완, 중도 전환, 기존 저장 업그레이드, 손상 거부, 실제 reducer에서 전체 교수 생애·1배/16배 결과 일치, IndexedDB의 열린 선택 복원·중복 적용 방지를 확인했다.

전체 Vitest 392개·23파일과 기존 Node 경제·경력 검사 37개, 총 429개 통과. 동시 실행에서 생긴 5초 시간 초과는 작업자 수를 2로 제한해 동일 검사로 재확인했다. 최종 전체 로그는 `.orchestrator/specialty-journey-full-tests-final.log`에 있다. 최종 타입 검사 및 Vite 빌드 통과. 번들에는 500kB 초과 안내가 남으며 이번 출력 JS는 약 683kB, gzip 약 218kB였다. 다른 채팅의 기능도 포함된 공유 워크스페이스 빌드 수치다.

UI는 사용자 저장을 쓰지 않는 `game/tests/browser/specialty-journey.html`에서 실제 생성·선택 함수를 검수했다. 390×844에서 내과 분과 목록의 마지막 선택까지 실행, 문서 폭/스크롤 폭 모두 390px, 선택 카드 폭 374px. 1280×900에서 부교수 승진 후 직함·정교수 요건·새 실적 0/0/0 표시 확인. 콘솔 오류·경고 0. 증거는 `.orchestrator/ui-qa/specialty-journey/`의 PNG와 `qa.json`에 있다. 이는 격리된 실제 컴포넌트 검수이며 전체 게임을 사람이 자연스럽게 플레이한 평가를 대신하지 않는다.

이번 작업의 공개 배포는 하지 않았다. 전체 게임 완성, 모든 과의 현행 제도 인증, 실제 교수 급여·임용 경쟁을 완성했다고 보지 않는다.
