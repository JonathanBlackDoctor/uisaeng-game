# 한 판 분량 약 70% 조정

2026-10-14 사용자 `pacing-seventy-percent-v1` 승인. 전체 사건 종류와 선택지, 사건 본문·결과 문구를 보존하면서 새 이야기의 한 판 분량을 줄인다. 이번 요청은 로컬 구현이며 공개 배포는 포함하지 않는다.

## 적용 방식

- 새 career 게임에만 `progress.pacingVersion: 1`을 저장한다. 없는 기존 저장은 기존 속도·9개 서사 슬롯·능력 및 무작위 사건 설정으로 이어진다. 진행 중이거나 열린 선택에 새 설정을 강제로 적용하지 않는다.
- 새 게임의 월 진행 시간은 대학 3.9초, 이후 0.325초다. 선택 대기 제외 기본 진행은 738초에서 479.7초(약 8분)로 줄어든다. 대학 비중은 약 58.5%를 유지한다. 나이·게임 내 기간·월별 경제 및 활동 계산은 유지한다.
- 연결 노트 이야기 또는 동기 이야기 중 하나를 시작 시드로 고른다. 선택된 이야기의 대학→수련→직업→은퇴 네 장면과 분기·후속 결과는 모두 유지한다.
- 전공별 생활 장면 한 슬롯과 시드로 정한 생애 단계의 일반 생활 장면 한 슬롯을 더해 기본 서사는 총 6개다. 미수련 등 전공별 장면이 없는 경우에는 일반 생활 장면을 배정한다. 일반 생활 이야기 24개와 두 연결 이야기, 전공 이야기 26개 모두 다른 판에서 등장할 수 있다.
- 능력 선택 사건은 한 판에 1회, 12개월마다 하는 일반 생활 사건 추첨의 통과값은 0.035다. 능력의 월별 성장·생활 효과는 유지한다. 실제 의료·생활의 발생 확률을 뜻하지 않는다.
- 동아리·전공·수련 여부·관계 방향·취업 경로 등 필수 선택, 전공별 수련·업무 사건과 분과·교수 경로는 축소하지 않는다. 이미 시작한 이야기의 자동 후속 결과는 슬롯 제한과 관계없이 진행한다.
- 사건별 선택지를 합치거나 삭제하지 않는다. 전체 이벤트 목록은 그대로이며 이 설정은 한 판의 노출량을 조절한다.

## 조정 전후 측정

`node scripts/measure-pacing.mjs`는 같은 선택 전략과 시드 1~10을 사용해 미수련·전문의 기본·연구교수 경로를 구·신 설정 각각 10회, 총 60회 완주한다. 매 행동 뒤 저장 상태의 유효성도 검사한다. 상세는 `.orchestrator/pacing-70-measurement.json`에 기록한다. 재지원·연애·모든 선택 조합을 망라한 최대·최소 범위는 아니다.

| 경로 | 이전 선택 수 | 변경 후 선택 수 | 평균 예상 시간 전→후 | 시간 비율 |
|---|---:|---:|---:|---:|
| 미수련·일반진료 | 35~41 | 26~29 | 25.1분→17.2분 | 68.3% |
| 전문의 기본 | 47~51 | 37~40 | 28.6분→20.8분 | 72.8% |
| 연구·교수 | 58~61 | 45~51 | 32.3분→24.0분 | 74.5% |

시간은 기본 1배속 진행에 선택 1회당 읽고 결정하는 시간 20초를 더한 추정이다. 실제 사람의 플레이 시간은 아니다. 세 경로 합산 예상 시간은 이전의 약 72.1%, 선택 수는 약 77.4%, 필수 사건 본문·선택 문구의 글자 수는 약 76.5%다. 필수 과정이 긴 교수 경로를 억지로 잘라 모든 지표를 정확히 70%로 만들지 않는다.

최신 표는 같은 작업공간에서 병행 추가된 성별·병역 콘텐츠까지 포함한 2026-10-14 01:10 KST 소스의 비교다. 조정 전후 모두 그 콘텐츠를 포함하고 pacingVersion만 달리해 측정했다. 해당 추가 전에는 미수련 32~37→22~25회, 전문의 43~47→33~37회, 연구교수 53~57→42~46회였고 합산 예상 시간은 70.4%였다. 서로 다른 소스의 수치를 같은 측정으로 취급하지 않는다. 최신 보고서에는 전체 소스 해시를 저장하고, 측정 도중 소스가 바뀌면 기존 보고서를 덮어쓰지 않는다.

기존 대화의 전체 선택지 773개 집계에는 경력 장면의 결과 문자열도 선택지로 센 오류가 있었다. `PathScene.choices`는 선택 문구·결과 문구 쌍을 저장하며, 실제 경력 사건은 기본 3개와 조건부 재활용 선택 1개를 렌더링한다. 이번 비교는 실제 생성된 선택 사건과 그 문구를 계측하며 이 잘못된 총수를 기준으로 삼지 않는다.

## 검증 범위

새 테스트는 모든 58개 서사 정의의 시드별 도달 가능성, 필수 선택 및 선택된 연결 이야기 네 단계, 자동 후속 결과, 1배/16배 결과 동일성, 기존·신규 저장의 소수 월 진행과 열린 선택 복원, 알 수 없는 설정 버전 거부를 검사한다. 기존 전공 사건 검사는 월 길이에 맞춰 진행하도록 수정했으며 기존 9슬롯·구형 시계 검사는 명시적으로 이전 저장 설정을 사용한다.

최종 분량·진로·저장 통합·시간 검사 4파일100개 통과, Node 경제/진로37개 통과, 타입 검사와 로컬 Vite 빌드 통과. 전체 검사 중 동시 추가 병역 기능에 따른 기존 fixture/나이 기대값 충돌11개를 수정한 뒤 해당 파일들을 재검증했고, 직전 통과한 나머지 검사는 재사용했다. 결과 로그는 `.orchestrator/pacing-integration-final.log`, `pacing-node-tests.log`, `pacing-build.log`. 빌드에는 기존과 같은 500kB 초과 청크 안내가 남는다. 이번에 브라우저 실제 사람 플레이 시간을 측정하거나 공개 배포하지 않았다.

위 통과는 검증 당시 소스 기준이다. 이후 다른 작업에서 identity.ts/career-runtime.ts를 수정하고 major-events.ts를 추가해, 01:14 최신 전체 타입 검사는 새 돌발이벤트 모듈의 `GameState.incidents` 미연결 오류로 실패했다. 해당 모듈을 이 분량 작업에서 덮어쓰지 않았으며 병행 작업 완료 후 전체 통합 검증이 필요하다. 측정 당시 입력 해시와 다른 현재 소스의 최종 수치로 위 표를 인증하지 않는다.
