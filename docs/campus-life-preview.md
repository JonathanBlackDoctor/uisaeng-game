# 대학생활과 생활 소식

사용자 결정 `campus-diversity-and-continuous-events-v1` 구현. 실제 제도·기관 관행이 아닌 가상 이야기와 변경 가능한 시험 설정이다. 규칙은 `campus-stories-provisional-2`이며 기존 career-preview-v1 저장을 이어 읽는다.

- 농구·밴드·지역 봉사·연구·사진·등산 중 활동을 고른다. 각 동아리는 서로 다른 선배, 반복되는 일상, 공동 활동, 후속 전공 탐색을 갖는다. 함께 맡은 일은 세 달 뒤 끝나며 선배와 경험이 쌓이고 후속 선택으로 관심 전공이나 관계가 달라진다.
- 대학의 조별 과제·방학·실습 질문·졸업 준비 선택을 둔다. 고정된 여섯 차례 견학을 제거했다. 이미 선택을 기다리던 옛 견학·가입·학비 화면은 원래 선택을 마친 뒤 새 콘텐츠로 이어간다.
- 선택 없는 소식이 대학에서는 매월, 이후에는 여섯 달마다 추첨된다. 두 슬롯 이상 조용하지 않도록 하며 활동과 동아리에 따라 후보 가중치가 달라진다. 40개 공통 대학 소식, 동아리별 세 소식, 성인 일상 18개가 능력치·경험·탐색에 영향을 준다. 사용 횟수가 적은 소식을 먼저 보여주고 충분한 간격 뒤 다시 사용하므로 사건 수 상한 때문에 생활이 멎지 않는다.
- 최근 소식 한 건과 효과를 장면 위에 표시한다. 이전 소식은 생애 기록에 남는다. 실제 월별 seed 진행이므로 같은 저장과 선택은 배속이 달라도 같은 결과를 낸다. 선택 대기·일시정지·오프라인 동안 새 사건이 발생하지 않는다.
- 학비·생활비 부족 시 직접 마련하는 기본 동작을 유지한다. 플레이어가 명시적으로 선택하면 재학 중 부족액만 대출·납부한다. 수입·지출에서 중단할 수 있고 졸업 시 종료한다. 이미 남은 미납에도 현금을 먼저 사용하고 부족분만 차입한다.

검증: 캠퍼스 17개 포함 Vitest 107개, 경력·경제 Node 테스트 37개 통과. 6동아리의 프로젝트→선배→전공, 저장 후 동일 결과, 1배속/8배속 동일성, 후반/반복 소식 지속, 구버전 pending, 동의/차입/중단/중복/졸업 종료 확인. 실제 PC·390px 모바일에서 표시와 저장 복원을 별도 확인한다.

전공별 업무·수련·사건·경제·위험 및 병원별 차이의 추가 심화는 다음 승인 개발 범위이며 이 대학생활 변경만으로 전체 게임 완성을 의미하지 않는다.
