# 무작위 대학과 입학 나이

2026-10-15 사용자 요청: 입학할 대학과 재수·N수에 따른 입학 나이에 무작위 요소를 적용한다.

새 게임 통지서에서 의대·치대·한의대·간호대를 무작위 배정한다. 각 대학 25%, 입학 나이는 20세 현역 65%, 21세 재수 23%, 22세 3수 8%, 23세 4수 3%, 24세 5수 1%로 시험 설정했다. 분포·상한은 변경 가능한 게임 조정값이며 실제 입시 통계나 사용자 확정 수치가 아니다. 개별 대학교 이름을 배정하는 기능은 포함하지 않는다.

통지서에 입학 나이와 수험 경로를 표시하고 첫 생애 기록에 남긴다. 배정은 시드로 재현되며 기존 배경·사건 난수 흐름은 유지한다. 대학별 교육·수련 경로는 기존 구현을 따른다. 현재 진행 중인 저장의 대학·입학 나이는 다시 추첨하지 않는다. 입학 나이가 없는 구형 저장은 기존 19세로 복원한다.

후속 사용자 요청으로 실제 나이·건강 부담에 따른 노화와 은퇴를 연결했다. 늦은 입학으로 은퇴 나이가 뒤로 밀리지 않는다. 상세 시험 설정은 `aging-and-retirement.md`를 따른다.
