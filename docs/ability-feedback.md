# 능력 표시 간소화 · 2026-10-13

사용자 피드백: “능력치가 너무 많아서 안 열어보게 되고 영향이 잘 안 느껴져.”

이번 변경은 표시 방식 개선이다. 건강·행복·지식·관계, 기존 30개 세부 능력의 계산·성장·선택 조건·저장 구조는 유지한다. 새 핵심 규칙을 확정한 것으로 기록하지 않는다.

- 능력 창은 현재 활동 또는 열린 능력 사건과 관련된 세 항목으로 시작한다. 다른 분야와 전공 숙련은 `다른 능력 보기`에서 찾는다.
- 각 항목의 대표 수치는 현재 수행력 하나다. 쌓은 실력과 컨디션 차이는 항목을 펼치면 보인다.
- 활동 아래에서 실제 focusAbilityModifier의 유리/불리 방향과 관련 대표 능력의 이번 달 변화 최대 두 개를 표시한다. 과거 변화는 이번 달 변화로 표시하지 않는다.
- 능력 사건의 선택창에는 실제 현재 수행력과 추가 선택의 필요 수치를 표시한다. 선택 가능 여부는 저장된 선택지를 따른다. 다른 사건에는 임의 능력 조건을 붙이지 않는다.
- 모든 표시는 읽기 전용이며 난수·저장을 수정하지 않는다. 능력 효과의 크기를 강화하거나 30개 능력을 통합하는 밸런스 변경은 이번 범위에 포함하지 않았다.

검증: abilities.test.tsx 18개 통과, tsc -b 및 Vite production build 통과. 기존 500kB 초과 묶음 경고 유지. 로컬 5198의 별도 저장에서 390×844·1024×768 화면, 기본 세 항목, 다른 분야 전환, 선택 대기 중 능력창 열기/닫기, 새로고침 뒤 선택 후보·능력 수치·성장량 복원 확인. 콘솔 경고/오류 0, 모바일 가로 넘침 없음. 능력 사건 조건은 자동검사로 확인했으며 실제 브라우저에서 해당 사건까지 진행하지 않았다. 전체 생애 재검수·실제 Safari·공개 배포는 미실행.
