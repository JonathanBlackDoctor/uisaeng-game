# 이벤트 선택 정리

2026-10-13 사용자 지시, 2026-10-14 구현·검수. 장학금처럼 신청하지 않을 이유가 없는 선택을 전체 이벤트에서 점검했다. 무조건 이득인 신청에 억지 불이익을 붙이지 않는다. 단순 처리와 결과 확인은 자동 진행하고, 시간·회복·경험·후속 경로가 갈리는 상황에서 선택을 받는다. 세부 수치는 조정 가능한 게임 설정이다.

## 자동으로 처리하는 일

- 대학 첫 장학금은 기존 시점과 선발식으로 한 번 신청·심사한다. 결과는 생활 소식과 기록에 남고, 선발된 경우 다음 달부터 기존 월 지원을 받는다. 이미 지원받는 저장은 재심사하지 않는다.
- 미납이 생기면 기존 일회성 생활 지원을 먼저 적용한다. 현금으로 낼 수 있으면 납부한다. 남는 부족액에 대해서만 대출·단기 일·재학 중 자동 대출 계획을 묻는다. 무료 지원을 자동 대출보다 먼저 적용한다.
- 수련 합격 결과는 기록하고 이어간다. 불합격 후 재지원·일반진료·연구는 계속 선택한다.
- 졸업·수련 이후·은퇴·최종 회고의 단순 ‘계속’ 버튼을 없앤다. 해당 단계의 필요한 진로 선택은 유지한다.
- 분과·세부 수련의 심사 경험을 충족하면 수료 결과를 자동 기록한다. 경험이 부족할 때 추가 준비와 중단은 계속 선택한다.
- 이전 random 경로의 학습 지원 신청·단계 확인도 자동 처리한다.

## 실제 결과가 갈리는 선택

- 동아리: 정기 모임에 공부 시간을 나누며 관계·연락망과 후속 활동을 얻는다. 가입하지 않으면 복습과 휴식에 시간을 쓴다.
- 능력 상황 전체: 직접 해결은 더 많은 연습과 학습, 도움받기는 부담 감소와 회복, 익힌 방법 활용은 중간 연습량과 협업으로 구분한다. 같은 성공 추첨에서도 연습량과 회복량이 달라진다. 문구와 실제 효과를 함께 바꾼다.
- 기본 수련 일정: 기록 검토는 공부와 숙련·안전관리, 동료 모임은 관계, 휴식은 회복으로 구분한다.
- 근무 교환 부탁: 일부 시간만 맡으면 남은 개인 약속을 지키고, 팀 전체 일정을 만들면 저녁 시간과 회복을 더 써서 조정 경험을 얻는다.
- 환자 안내문: 직접 정리하는 시간만큼 학습 효과를 높여 다른 설명 방식과 구분한다.
- 결혼·교제 여부에 스탯 보너스로 정답을 만들지 않는다. 관계 상태와 이어지는 이야기의 차이는 유지한다.

## 점검 범위와 저장

현재 career 경로와 이전 random 경로, 대학 사건, 일반 생활 서사, 연결 서사와 동기 관계, 26개 전공의 수련·업무 사건, 전문 분야·분과·교수 경로, 능력 사건을 읽고 점검했다. 수치 비교는 스탯뿐 아니라 비용·경험 분야·숙련·안전관리를 포함한다. 정체성 선호, 후속 기회, 이미 쌓은 경험으로 열린 선택은 단순 스탯 비교로 삭제하지 않는다. fixture/family는 이전 저장용 경로로 유지한다.

새 사건은 `choiceVersion: 1`로 구분한다. 이전에 열린 사건은 버전 없는 원래 템플릿으로 검증하고 원래 효과로 마친다. 읽기·일시정지·중복 행동으로 재추첨하거나 지원금을 중복 지급하지 않는다. 실제 제도·지원 자격·개인 확률에 관한 연구 원본은 수정하지 않았다.

검증 결과는 `.orchestrator/event-design-verification.json`에 저장한다. 숫자 비교와 자동 플레이 검사는 실제 이용자의 재미·체감 난이도 평가를 대신하지 않는다.
