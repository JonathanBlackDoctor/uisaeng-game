# 의생게임 1.3.0

사용자 지시 ‘변경된 모든 작업 묶어서 배포 완료했어?’ 이후 ‘배포해’에 따라 1.2.0 이후 완료된 변경을 기존 공개 주소에 함께 배포한다.

- 사건과 선택지를 짧고 구체적으로 정리하고, 기록에 상황·행동·실제 결과를 함께 표시한다. 최근 중요 기록8개를 보여주고 반복 일상 기록은 묶는다.
- 새 게임에서 기본/짧게 분량을 선택한다. 짧게는 시간 진행과 반복 생활 사건의 노출량을 조정하며 필수 선택·연결 이야기 결말을 유지한다. 기존 저장의 분량 설정은 유지한다.
- 상단에 현재 주활동·생활 활동·주간 여유 시간과 ‘시간·생활 바꾸기’를 표시한다. 주활동·생활 활동·식생활을 한 창에 모으고, 설정 중 시간 진행을 멈춘다.
- 여섯 능력이 활동과 사건의 수행·성과·부담에 작용하며 강점별 해결과 도움·심화 선택, 결과의 능력·피로·경험 설명을 추가한다. 실제 시작 배경에 근거한 짧은 능력치 설명을 표시한다.
- 새 돌발 피해 사건의 경제·건강·관계·회복 부담과 장기 영향을 강화하고 큰 사건·큰 실제 변화를 기록에서 강조한다. 기존 대기 사건과 이미 저장된 영향의 조건은 보존한다.
- 스탯·능력·숙련·최고값·증감·공유는 정수로 반올림 표시하며 계산·저장값은 보존한다. 입학 통지서의 종이·빛·순차 등장 동작과 동작 줄이기 대응을 추가하고 시작 병역 표시는 제거한다.

분량·능력 판정·피해액·영향 기간의 구체적인 계수는 변경 가능한 게임 조정값이다. 현실 제도나 개인 확률을 뜻하지 않는다. 공개 저장은 기존 기기·주소의 저장 경로를 유지하며 자동검사와 실제 사용자 브라우저 복원 확인을 구분한다. 기존 브라우저 접근 거부는 재시도·우회하지 않는다.

최종 고정본·통합 검사·이전 공개 저장 호환·CI·공개 배포 파일 동일성은 `docs/release-1.3.0-verification.md`와 `.orchestrator/github-sync/release-1.3.0-state.json`에 기록한다.
