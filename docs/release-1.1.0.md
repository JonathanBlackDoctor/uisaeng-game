# 의생게임 1.1.0

2026-10-14 사용자 요청: “현재 수정된 사항들 모두 모아서 다음 버전으로 배포하자.”

## 이번 통합 내용

- 상세 능력을 판단력·술기·소통·연구력·운영력·자기관리 여섯 가지로 통합하고 이전 저장을 호환한다.
- 전공별 이야기, 분과·세부 수련과 교수·기초 연구 진로를 확장한다.
- 단순 신청·결과 확인은 자동 처리하고 실제 결과가 다른 선택에 집중한다.
- 상단 핵심 수치, 생활 장면과 기록 배치, 재정 요약, 정지 안내와 능력치 변화 표시를 개선한다.
- 활동·생활 단계와 인물 상태에 맞는 장면과 애니메이션을 반영한다.
- 새 게임의 분량을 줄이되 진행 중인 기록의 속도·열린 선택과 이야기 흐름을 유지한다.
- 성별별 생활 사건과 현역병·의료인 복무 선택, 복무 급여·나이·전역 후 복귀를 반영한다.
- 큰 영향을 남기는 돌발 사건 50종과 직업·전공별 의료 분쟁, 대응·소송·종결 및 장기 영향을 추가한다.
- 가족과 보낸 시간·길러낸 제자를 생활 활동, 저장, 회고와 공유 결과에 연결한다.
- 전공과 관련 능력의 시너지를 성장·활동 보상·추가 수입과 현재 배율 표시에 반영한다.
- 장소·전공·계절·복무·가족·생활 활동에 맞는 배경·복장·소품을 확장한다.

고정된 통합 소스에 전체 테스트·타입 검사·운영 빌드와 실제 화면·저장 호환 검수를 실행한 뒤 기존 공개 주소에 배포한다. 세부 검증 및 공개 확인 결과는 배포 후 기록한다. 시뮬레이션 수치와 제도 표현은 게임 설정이며 실제 개인의 결과나 의료 제도를 재현하는 값이 아니다.
