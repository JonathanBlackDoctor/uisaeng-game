# 필수 선택과 대학생활 플레이 시간

2026-10-12 사용자 결정 `required-life-choices-and-university-playtime-v1`의 구현 요구사항이다. 방향은 확정됐으며 아래 구현 기준은 이를 구체화한 개발 해석이다. 세부 자격·수치·문안의 확정을 대신하지 않는다.

## 확정 방향

2026-10-13 추가 확정 `physician-career-specialty-primary-goal-v1`: 게임의 테마는 **의사로서의 진로를 선택하는 것**이다. 어떤 전공 과를 택할지 정하는 과정은 **대학생활의 1차 목표**이며 반드시 구현한다. 대학생활에 절반 이상의 시간을 배정한다는 결정은 전공 선택의 중요도를 낮추는 뜻이 아니다. 대학에서 전공을 알아가고 준비해 진로를 결정하는 흐름을 중심에 둔다. 수련하지 않는 길도 기존 결정대로 진로 선택에 포함한다.

동아리에 들어갈지, 어떤 전공으로 수련할지 또는 수련하지 않을지, 결혼을 어떻게 생각할지 같은 핵심 선택 기회는 무작위 추첨에 실패해서 생략되면 안 된다. 게임의 중심은 대학생활이며 전체 플레이타임의 절반 이상을 여기에 배정한다. 나머지 필수 선택 전체 목록은 아직 미정이다.

## 진로 중심 구현·검수 기준

아래는 확정된 테마를 구현하기 위한 개발 기준이다. 세부 사건·자격·판정식·수치를 새로 승인한 것은 아니다.

- 대학생활에서 전공에 대한 관심과 정보를 얻고, 경험을 비교하고, 준비하여 진로를 결정하는 흐름을 연결한다. 마지막에 과 이름만 고르는 화면으로 충족했다고 계산하지 않는다.
- 실습·학업·연구·선배와의 만남 같은 경험이 진로 탐색·준비에 어떻게 이어졌는지 플레이어가 알 수 있어야 한다. 모든 일상·연애 사건을 진로 도구로 만들 필요는 없다.
- 전공·수련 여부를 결정하지 않은 채 일반적인 다음 장 버튼만으로 수련·직업 단계에 넘어가지 않도록 한다. 유예를 제공하면 미해결 결정을 보존하고 다음 기회를 관리한다. 결정 시점과 실제 지원·선발 시점은 구분한다.
- 선택한 전공·진로가 이후 수련·경력 사건과 생활에 이어지도록 구현·검수한다. 전공별 차이의 크기와 상세 내용은 미정이다.
- 개발 우선순위는 진로 탐색·준비·필수 선택·후속 결과를 연결하는 플레이 경로다. 일반 생활 사건의 개수나 화면 완성도만으로 중심 목표 달성을 보고하지 않는다.
- 검수는 대학 경험 → 진로 비교·준비 → 필수 결정 → 이후 결과의 연결과 저장·재개를 확인한다. 전공별 지원 자격·선발은 실제 제도 근거와 게임 가정을 구분한다.

## 누락 방지 구현 기준

- 필수 선택은 일상 사건 추첨과 별도로 도달 여부·해결 여부를 관리한다. 자연스럽게 먼저 발생한 선택은 재사용하고, 미해결 선택은 해당 시기 끝까지 놓치지 않도록 보장한다.
- 동아리 가입과 미가입 모두 유효한 선택으로 기록한다. 미가입을 미응답으로 취급해 계속 가입을 요구하지 않는다.
- 전공·수련 결정에는 수련하지 않는 경로를 제공한다. 상세 지원 자격과 합격 결과는 별도 규칙이며, 모든 전공에 무조건 진입할 수 있다고 가정하지 않는다.
- 결혼 관련 결정은 관계 상태에 맞는 맥락을 제공한다. 상대가 없는데 배우자를 생성하거나 결혼을 강제하지 않는다. 구체적인 연애·결혼 장면의 조건과, 미혼 상태에서 결혼에 대한 방향을 생각하는 선택은 구분해 설계한다. 문안·시점은 미정이다.
- 미루기를 제공한다면 후속 기회를 관리한다. 무응답이나 단계 전환만으로 임의 결말을 확정하지 않는다.
- 배속으로 여러 시간 경계를 지나도 필수 선택을 건너뛰지 않는다. 선택 대기 정지, 저장·재개 시 같은 선택 복원, 응답 중복 방지를 함께 적용한다.

무작위성은 만남의 경로·인물·시기·상황·결과와 일상 사건에서 유지한다. 필수 기회 보장이 특정 결과 보장으로 바뀌어서는 안 된다.

## 대학생활 비중

게임 속 연수와 실제 플레이 시간을 구분한다. 대학생활을 중심으로 단계별 시간 진행 속도와 콘텐츠를 조정해 전체 플레이타임의 50% 이상을 배정한다. 같은 문구의 사건을 반복하거나 단순 대기만 늘리는 방식으로 충족했다고 계산하지 않는다. 대학에서의 활동·관계·선택이 이후 삶으로 이어지도록 사건과 후속 결과를 함께 배치한다.

총 목표 시간, 정확한 배분율, 단계별 속도, 선택을 읽는 시간의 측정 방식은 미정이다. 임의 일시정지·자리 비움·배속 사용은 측정 조건으로 명시해야 하며, 진행 시간 비율만 확인하고 실제 플레이타임 목표 달성을 선언하지 않는다.

## 현재 구현과 남은 검증

2026-10-13 사용자 추가 우려: “같은 이벤트나 선택지가 너무 많이 반복되진 않겠지?” 현재는 동일 사건 종류에 게임 속 6개월의 재등장 대기만 적용하고, 한 판의 누적 등장 상한이나 최근 선택 내용의 유사도 제한은 없다. 기본 속도에서는 대기 시간이 진행 시간 6초에 해당하며 선택을 읽는 시간은 별도다. 따라서 반복이 충분히 억제됐다고 답하거나 대학 분량을 기존 사건 반복으로 채우면 안 된다.

후속 개발에서는 한 번 결정한 필수 선택의 재질문 방지, 일상 사건의 한 판 등장 제한·최근 사건 제외·미경험 사건 우선, 이전 선택과 상황 변화가 있는 후속 사건을 검토한다. 문구만 바꾼 동일 선택도 반복으로 점검한다. 이 항목들은 개발 제안이며 구체 횟수·간격은 아직 확정하지 않았다. 후보가 소진됐을 때 같은 사건으로 채우기보다 조용한 기간을 허용한다. 구현 후 전체 한 판의 동일 사건 횟수와 선택 내용 반복을 검증해야 한다.

현재 `random-preview-v1`의 동아리·결혼은 조건부 무작위 후보이며 기회 누락 방지가 없다. 전공 선택과 수련하지 않는 경로도 없다. 기본 시간 진행은 대학 72개월 / 전체 684개월로 약 10.5%다. 선택 읽기 시간을 제외한 비중이며 실제 플레이 시간 측정값은 아니다. 이번 결정 기록으로 게임 구현이 바뀐 것은 아니다.

구현 시에는 무작위 사건이 한 번도 발생하지 않는 경로에서도 필수 선택을 만나도록 검증한다. 가입·미가입, 수련·미수련, 관계 상태별 결혼 결정, 유예·저장·재개, 배속 경계 통과를 확인한다. 대학 비중은 대표 경로의 실제 플레이와 단계별 진행 시간·콘텐츠 분량을 함께 측정한다. 정식 자격 규칙과 전체 콘텐츠가 없으므로 전체 게임 완성으로 인증하지 않는다.
