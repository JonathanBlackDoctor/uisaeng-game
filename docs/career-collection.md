# 내 진로 기록 · 2026-10-14

## 진료실 도감과 생애 최고 기록 · 추가 구현

사용자 승인에 따라 메뉴 이름을 `진료실 도감`으로 변경했다. 26개 과는 미경험이면 닫힌 문, 수련 경험이면 열린 문, 전문의 취득이면 켜진 조명과 자격증으로 표시한다. 기존 장면의 과별 기구를 재사용하며, 소아청소년과에는 작은 침대를 둔다. 분과·세부 자격은 해당 플레이에서 실제 취득한 모전공의 방에만 장식한다. 여러 과에서 취득 가능한 동일 자격의 전체 집계는 한 번이다. 클릭하면 첫 수련·전문의 취득 플레이, 모은 자격, 전문 분야의 수련 상태를 확인한다. 도전과제는 접어 두고 검색·필터와 기존 분야 목록을 유지했다.

사용자의 후속 정정에 따라 생애 기록에는 진료실 그림 대신 **건강·행복·지식·관계의 최고값**을 추가했다. `이 생애`와 `모든 플레이`를 비교하고 역대 최고값을 기록한 첫 플레이를 표시한다. 보관된 회고는 선택한 생애의 값으로 표시한다. 기존 진로 기록 저장소의 선택적 `statHighs` 필드로 누적하므로 DB 버전 변경 없이 새 게임·재접속·백업에서도 남는다. 게임 상태에도 최고값을 두고 행동 전후 및 월별 결산 시 집계해 빠른 진행 중의 최고값을 보존한다. 게임 수치·확률·보상은 변경하지 않았다.

기존 저장에 없는 과거 최고값을 로그 효과로 역산하지 않는다. 확인 가능한 현재값부터 집계하며, 이미 삭제된 플레이와 최초 관측 이전의 최고점은 복원할 수 없다. 수치는 0~100의 유한값만 허용한다. 기존 저장의 읽기는 원본을 변경하지 않는다.

검증: 새 검사 7개와 기존 검사를 합친 Vitest 489개 중 전체 병렬 실행 486개 통과, 3개는 기존 5초 시간 제한에 걸렸다. 해당 3개를 단일 작업자로 재실행해 모두 통과했다(각 2.4~2.6초). 별도 Node 37개, TypeScript, Vite 빌드 통과. 월별/빠른 진행, 값 하락 후 보존, 새 게임·재접속·백업, 다른 탭의 오래된 저장 거부, 생애별 분리, 잘못된 값 거부, 실제 모전공의 공유 자격 장식을 검증했다. 브라우저에서 1280×900·390×844, 검색·빈 기록, StrictMode의 상세 창, Esc 후 원래 버튼으로 초점 복귀, 실제 앱 메뉴 연결을 확인했다. 콘솔 경고·오류는 없었다. `.orchestrator/ui-qa/clinic-rooms/`의 화면은 가상 검수 데이터이며 사용자 기록이 아니다. 빌드는 `.orchestrator/clinic-room-collection-build`에 분리했고 기존 500KB 번들 경고는 남는다. 공개 배포는 하지 않았다.

사용자 요청: 여러 플레이에서 경험한 전공과·분과를 모으는 공간을 만들고, 먼저 실제 전공과와 세부 자격의 연결을 구분한다. 이 구현은 해당 기능의 완료 기록이며 전체 제도 재현이나 게임 전체 완성 기록이 아니다.

## 화면과 집계

상단 `내 진로 기록`에서 26개 전공의 수련 경험·전문의 취득, 확인된 21개 분과·세부 자격, 146개 전공별 전문 분야의 수련 경험·완료를 모은다. 검색, 기록 있음/없음 필터, 최초 달성 플레이 순서와 4개 도전과제 진행률을 제공한다. 시작 화면에서도 열 수 있고, 열어 둔 동안 게임 시계는 기존 메뉴와 동일하게 멈춘다.

지원·불합격·견학만으로 수련 경험을 부여하지 않는다. 기존 엔진이 전문의 이후로 취급하는 수련 종료 단계(수련 시작 + 72개월, 지연 반영)에 도달했을 때 전문의 취득을 집계한다. 이 72개월은 기존 게임의 전체 수련 단계이며 실제 과별 레지던트 기간을 뜻하지 않는다. 같은 자격은 다른 과에서 취득해도 도전과제에서 한 번만 센다. 보상 스탯이나 새 확률은 추가하지 않았다.

## 제도 분류와 게임 규칙

`credential-catalog.ts`는 내과 9개, 소아청소년과 9개 분과, 수부외과·소아응급의학·소화기내시경 세부 자격을 다룬다. 내과와 소아청소년과 분과는 해당 모전공과만 연결한다. 수부외과는 정형외과/성형외과, 소아응급은 소아청소년과/응급의학과, 소화기내시경은 내과/외과/소아청소년과에서 연결된다. 소화기내시경은 소화기내과 분과와 별도 자격이다.

기존 `field-N` ID와 배열을 유지했다. 소화기내시경은 새 저장에서만 `credential-endoscopy`로 추가된다. 나머지 분야는 전문 분야 수련으로 남긴다. 목록에 없다는 이유로 실제 자격이 존재하지 않는다고 주장하지 않는다. 중환자의학, 소아외과 등 아직 분류하지 않은 제도가 남는다. 이 21개는 국내 전체 공인 자격의 목록이 아니며, 학회 인증을 국가 전문의 면허와 동일시하지 않는다.

새 플레이는 journey version 2를 사용한다. 확인된 자격 경로에는 `수련 완료 → 교육·연구 자료 준비 또는 자격 취득 생략 → 자격시험 응시 또는 생략`을 적용한다. 수료만으로 분과전문의라고 표시하던 처리를 없앴다. 준비를 생략해도 수련 경험과 교수 경로는 남는다. 공통 수련 24개월·추가 준비 6개월과 준비 후 응시 시 합격은 **변경 가능한 게임 가정**(`credential-provisional-1`)이다. 실제 학회별 회원기간, 수련병원 지정, 평점, 발표·논문, 시험 일정·합격률, 갱신과 예외를 전부 시뮬레이션하지 않는다. 정식 수련 규칙 승인으로 기록하지 않는다.

## 저장과 호환

IndexedDB를 v1에서 v2로 올리며 `careerRecords` 저장소만 추가한다. 기존 현재 게임·회고를 지우거나 다시 쓰지 않는다. 저장할 때 같은 트랜잭션에서 현재 상태·회고·누적 기록을 처리한다. 이전 플레이를 새 게임으로 교체할 때 중도 종료한 전공 경험도 보존한다. 저장 실패·두 탭 충돌은 상태와 기록 모두 되돌리며, 동일 runId/달성 키를 중복 집계하지 않는다. 변경이 없는 누적 기록은 재기록하지 않는다.

옛 현재 저장과 보관된 회고는 유효성 검사를 통과한 상태에서 읽어 합산한다. version 1의 진행 조건과 열린 선택은 유지하고, 기존 수료 기록에 새 자격시험 합격을 소급하지 않는다. 새 자격 심사는 새 플레이부터 적용한다. 브라우저 데이터 삭제 및 이미 지운 과거 플레이는 복구할 수 없고 기기 간 동기화는 없다. 기존 원본 백업 JSON에 누적 기록을 포함했다. 최초 플레이 순서는 기록 가능한 최초 저장 시각(옛 회고는 보관 시각)을 기준으로 하며 삭제된 회차는 복원하지 않는다.

## 검증

- 전체 Vitest 36파일 482개, 별도 Node 진로·경제 37개 통과.
- 새 검사 11개: 전체 자격 경로의 실제 진행, 자격 심사 건너뛰기·조기 시험 거부, 수료/취득 구분, 과를 넘는 동일 자격 중복 제거, 새 게임·재접속, DB v1 업그레이드, 실패 원자성·다른 탭 충돌, 실제 reducer의 자격시험 저장복구와 회고 완료.
- TypeScript 검사와 분리된 Vite 빌드 통과. 출력은 `.orchestrator/career-collection-final-build`. JS 약 799KB, gzip 약 257KB이며 기존 500KB 번들 경고가 남는다. 공유 작업공간의 다른 기능도 포함된 수치다.
- 실제 브라우저: 독립 검수 화면에서 390×844와 1280×900 레이아웃, 검색, 기록 필터, 빈 기록, 공유 자격 중복 제거를 확인했다. 실제 앱에서 새 메뉴 진입도 확인했다. 콘솔 오류·경고 0. 증거는 `.orchestrator/ui-qa/career-collection/`에 있다. 가상 검수 상태를 썼으며 사용자 플레이 기록을 생성하거나 덮어쓰지 않았다.

공개 배포는 실행하지 않았다. 기존 research 원본, 다른 채팅 수집물과 작업 보류는 변경하지 않았다.
