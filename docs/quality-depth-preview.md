# 선택과 인물이 이어지는 생애

상태: 구현·검수·공개 배포 완료. 담당 채팅 `01a1359a-7bd9-77c1-80d7-78f453380680`. 공개 근거는 `docs/quality-release-20261014.md`에 기록했다.

2026-10-13 사용자 원문: “좋아. 그거 다 구현해서 배포 안 된거까지 배포까지 완료해.” 승인 범위는 앞서 제안한 선택 후속·전공별 경험·주변 인물·결과 피드백·실제 플레이 점검 및 기존 공개 GitHub Pages 주소 반영이다.

이번 변경 파일: relationships.ts, specialty-chapters.ts, life-stories.ts, career-runtime.ts, choice-feedback.ts, ChoiceFeedback.tsx, choice-feedback.css, main.tsx, DecisionSheet.tsx, LifePanels.tsx, LifeScene.tsx, quality-depth.test.tsx. 기존 별도 채팅의 오프닝·능력 안내·1.0.0 표기를 보존해 통합한다. 자동 큐/에이전트 배정은 하지 않는다.

동기는 시작 시드로 정해지는 이름과 진로를 갖는다. 대학 실습→수련 시기 각자의 생활→직업 모임→은퇴 뒤 만남까지 네 사건을 기존 슬롯에 넣는다. 자료 교환을 택했을 때만 공동 작업 제안이 열린다. 다른 경로에서는 참석 또는 안부를 택한다. 거절한 일은 동료들이 마치며 만남은 이어질 수 있다. 주변 사람과 회고에 실제 결정과 직업 변화를 표시한다.

전공 26개의 직업 사건은 서로 다른 상황과 구체적인 행동을 제공한다. 실제로 기록된 해당 전공 수련 선택이 있을 때만 그 경험을 꺼내 쓰는 추가 선택이 열린다. 무료 대안은 항상 있다. 진료 결과의 옳고 그름이나 실제 위험률로 평가하지 않는다. 연구·미수련 경로는 기존 공통 사건을 사용한다.

연결 노트 4슬롯+동기 4슬롯+직업 사건 1슬롯으로 생애 9개 선택 제한과 시간 설정을 유지한다. 후속은 3개월 뒤 자동 기록이며 선택창을 더 열지 않는다. 기존 pending 사건 본문·후보는 그대로 복구하고 해결 뒤 새 인물 상태를 추가한다.

선택 결과는 IndexedDB 저장 성공 뒤에만 표시한다. 실제 전후 스탯 차이와 현금 차이를 쓰므로 상한에서 얻지 못한 점수를 표시하지 않는다. 결과는 다음 선택창에서도 읽을 수 있고 평상시에는 8초 뒤 사라진다. 학습 결과는 장면의 책, 실제 소개된 동기는 장면과 주변 사람에 연결한다.

전체 자동 회귀·새/구 저장·PC/모바일 실제 플레이·CI·공개 자산 확인 뒤 아래에 결과를 기록한다. 사람을 모집한 사용성 평가는 시행하지 않았으며 직접 플레이 점검과 구분한다. 게임 효과와 간격은 변경 가능한 시험 조정값이다.

검증: 고정본 TypeScript 통과, Vitest 315개/20파일과 Node 37개 통과. 전공 26개마다 수련 기록 유무에 따른 후보 변화, 동기 세 분기와 선택 불가 후보 차단, 대기 선택 IndexedDB 복구, 1배·16배 동일성, 기존 생애 경로 회귀 포함. 같은 시드42 미수련 경로는 37선택/능력4/이야기9/684개월이며 가장 많이 반복한 제목은 2회다. 실제 사람의 플레이 시간 측정과 구분한다.

실제 브라우저 390×844에서 사진 동아리→영상의학과/서울대병원 합격→봉직의→은퇴 완주. 지민과 실습 분담→자료 교환→공동 작업→편지 분기, 수련의 ‘이전 자료를 더 찾는다’를 직업 사건에서 활용, 557기록·주변 인물·회고 복원 확인. 가로 넘침과 콘솔 경고/오류 없음. PC1024×768도 확인. `.orchestrator/ui-qa/quality-depth/`에 PNG와 결과를 보존한다. 다른 전공의 실제 UI 완주는 하지 않았으며 자동 회귀 범위와 구분한다.

이 배포는 완료된 오프닝·능력 표시 간소화와 누적 진료/순자산 표시도 함께 검수한다. 이후 별도 채팅에서 시작한 분과/교수 진로, 추가 장면·밸런스 작업은 이 고정본 범위 밖이며 루트 변경을 보존한다. 이전 고정본과 새 고정본을 덮어쓰지 않는다. 번들 500kB 경고가 남으며 이는 빌드 오류가 아니다. 공개 완료 근거는 배포 후 별도 릴리스 기록에 남긴다.
