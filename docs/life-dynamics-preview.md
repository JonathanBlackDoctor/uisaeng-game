# 성과 누적·스탯 하락·재산 표시

2026-10-13 사용자 지시에 따른 로컬 구현. 세부 확률·증감·피로·수입 보정은 `DYNAMICS_RULES`와 해당 모듈의 provisional 게임 설정이며 현실 통계나 정식 수치 승인이 아니다.

- `life-dynamics.ts`: 매월 지속 활동의 성과를 큰 실패·부진·보통·성공·큰 성공으로 추첨한다. 해당 스탯, 피로, 그 활동의 누적 성과가 다음 추첨 가중치에 영향을 준다. 모든 등급의 가능성은 남으며, 사용하지 않는 활동의 누적 성과는 서서히 중립으로 돌아온다.
- 준비 경험은 고정 월 +4 대신 성과에 따라 -2/0/3/6/9로 변한다. 대학 팀 활동·실습 질문·연구·임상 사례와 동아리 프로젝트, 전공 수련·업무의 지연된 결과도 성과에 연결한다. 단순 설정 변경, 대출·상환, 관계의 동의·진로 자체를 실패 추첨으로 뒤집지 않는다. 모든 기존 사건의 본문/고정 효과를 재작성한 것은 아니다.
- 석 달마다 실제 스탯 변화와 결과를 기록한다. 돌보지 않은 영역, 높은 스탯의 유지 부담, 과로와 부채는 하락 요인이다. 휴식은 피로를 줄이고 건강을 회복한다. 자동 소식은 최근 캠퍼스/성과 기록 한 건을 표시한다.
- 지속된 성과는 과외·아르바이트, 연구 수입, 개원 매출의 증감으로 이어진다. 약정 급여는 임의로 깎지 않는다. 줄어든 수입을 정정할 현금이 없으면 미납으로 남기며 돈을 새로 만들거나 자동 차입하지 않는다. 같은 월은 두 번 정산하지 않는다.
- 별도 저장 난수·누적 성과·피로·처리한 시도 ID를 저장한다. 화면 프레임·배속·저장 읽기는 추첨하지 않는다. 이전 저장은 다음 진행부터 새 상태를 추가하고 이미 끝난 프로젝트의 과거 성과는 소급 적용하지 않는다.
- `FinanceSummary.tsx`/`finance-view.ts`: 순자산=총자산−부채−미납액. 오른쪽에는 현재 연봉/연 수입 예상/연 매출 예상과 월 지출·월 잔여액을 표시한다. 대학 등록금은 예산에 월평균 원 단위 반올림으로 반영하되 실제 납부 주기는 유지한다. 개원 운영비 및 업무 일정 비용을 포함하며, 대출 원금 상환과 일회성 거래는 예상 예산과 별도다. 금액은 억·만 단위로 축약하고 펼친 내역에서 정확한 원 단위 금액을 확인한다.
