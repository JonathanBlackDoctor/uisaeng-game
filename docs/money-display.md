# 금액 표시 통일

2026-10-14 선택지 금액도 억·만 단위로 맞추자는 제안과 전체 수정사항 통합 배포 지시를 반영했다.

`money-format.ts`에서 정수 원 금액을 조·억·만·원으로 나눈다. 1,400,000원은 140만 원, 125,000,000원은 1억 2,500만 원, 3,842,716원은 384만 2,716원이다. 1만 원 미만은 원으로 표시한다. 음수와 + 표시를 유지하며 반올림하거나 금액을 변경하지 않는다.

선택창 제목·본문·행동·설명, 선택 결과, 최근/전체 기록, 재정 상세·이자·손익, 배경·월 지원, 병원 운영, 회고·공유 결과에 같은 기준을 쓴다. 숫자만 있는 원 금액을 화면에서 변환하며 이미 적힌 억·만 표현, 나이, 퍼센트, 인원은 보존한다. 원 단위의 정확한 숫자 툴팁과 JSON 백업은 유지한다.

저장된 사건 원문·선택 ID·비용·경제 계산은 수정하지 않는다. 이전에 열린 선택도 원본으로 검증하고 표시만 바꾼다. 전용12개 및 관련32개 검사와 타입 검사를 통과했다. 최종 배포 고정본에서 전체 회귀·이전 공개 저장 호환을 별도로 검사한다. 브라우저 권한 거부 때문에 이번 화면 검사는 실제 DOM 접근 대신 실제 컴포넌트의 서버 렌더링으로 확인했다.
