# 상단 요약과 생활·로그 배치

## 2026-10-14 화면 다듬기 후속 반영

사용자 지시 “모두 다 구현해”의 다섯 항목을 반영했다. 아래 내용이 이전 배치 설명보다 우선한다.

- PC 생활 영역과 기록 영역을 1.7:1로 배치하고 장면 높이를 180~240px로 늘렸다. 최근 기록은 최신순으로 위에 표시하며 최대 높이를 420px/48dvh로 줄였다. 원래 기록과 이전 기록을 읽는 동안의 위치 유지 동작은 보존한다.
- 좁은 화면에도 `선택 대기`·`일시정지`·`진행 중`을 표시한다. 저장 오류는 `저장 확인 필요`로 표시한다.
- 고정 상단에는 시간과 네 스탯을 남기고 재정은 스크롤되는 별도 줄로 분리했다. 모바일 누적 진료는 재정 내역 안에서 확인한다. 보유금·적자·미납은 요약에 남기며 상세는 기본적으로 접힌다. 모바일 상세는 본문 안에서 펼쳐진다.
- 실제 기록 ID로 입학·단계 전환·수련 지원 결과·자격·진로 주요 기록을 강조한다. 연속된 동일 단계·제목·종류의 생활/재정 기록은 묶고, 중간 선택은 묶지 않는다. 최근 기록과 전체 생애 기록에 적용하며 원본 저장 데이터는 바꾸지 않는다.
- 선택 결과의 실제 스탯 차이를 숫자 옆에 5초간 표시한다. 상한/하한 적용 후 차이를 사용하며 새로고침 때 재생하지 않는다. 만료된 변화량은 기록 화면을 다녀와도 다시 표시하지 않는다. 동작 줄이기 환경에서는 등장 애니메이션을 생략한다.

검증: 최종 전체 TypeScript 검사와 Vite 운영 빌드 통과. 직접 관련 테스트 5개 통과(다른 32개는 해당 최종 실행에서 제외). 별도 실행에서 저장 9개·시간 조작 7개 통과. 앱 내 브라우저로 1280×900, 390×844, 320×740의 가로 넘침 없음, 재정 상세, 선택 대기/일시정지, 실제 선택의 건강·지식 +1 및 자동 종료, 새로고침 후 정지/기록 복원을 확인했다. 브라우저 오류·경고 없음. 캡처는 `.orchestrator/ui-qa/design-refinement-mobile.png`와 `design-refinement-desktop.png`에 저장했다.

공유 작업 폴더의 병행 변경 중 `quality-depth.test.tsx`의 “replaces existing slots and leaves nine scheduled story decisions per life”는 `story:peer-distance` 대신 null을 받아 실패했다. 해당 게임 진행 로직은 이번 UI 작업에서 수정하지 않았다. 따라서 전체 회귀 테스트 통과를 주장하지 않는다. 별도 테스트 보조 파일 타입 오류는 이후 그 파일이 갱신된 뒤 전체 타입 검사 통과를 확인했다. 기존 큰 JS 번들 경고는 남으며 공개 배포는 하지 않았다.

## 이전 배치와 검증 기록

2026-10-14 사용자 지시 “좋아. 그렇게 구현해.”에 따라 화면 구성을 변경했다.

- 상단: 시간 조작과 건강·행복·지식·관계, 누적 진료·순자산·수입·지출을 압축해서 표시. 기본 정보는 스크롤 중에도 고정하고 재정 상세는 펼쳐 본다. 미납은 요약에 계속 표시한다.
- 본문: PC와 태블릿은 생활·조작 60%, 로그 40%. 생활 장면은 150~180px. 활동과 진로 설정은 현재 상태와 변경 버튼을 먼저 보여주며 상세를 펼친다.
- 로그: 발생 순서대로 최신 기록을 아래에 추가. 아래를 보고 있으면 따라가고 이전 기록을 읽는 중이면 위치를 유지하며 새 기록 버튼을 제공한다. 연속된 같은 단계·제목의 주기적 생활 결과만 묶고 원래 기록과 실제 변화량은 모두 남긴다.
- 모바일: 상단 요약, 생활·조작, 로그 순서. 기존 선택 모달이 열리면 상단 상태를 모달 위의 남은 공간에 표시한다. 짧은 가로 화면에서는 상단 고정을 해제한다.

구현 파일: `game/src/PlayOverview.tsx`, `PlayLog.tsx`, `play-layout.css`, `main.tsx`, `CareerPanel.tsx`. 기존 생애 규칙·시간·저장 스키마 변경 없음. 생활 소식의 중복 표시를 통합 로그로 대체했다.

검증: 타입 검사, Vite 운영 빌드, 관련 Vitest 30개 통과. 1280×900, 1024×768, 768×1024, 390×844, 320×740의 Chromium 화면에서 가로 넘침 없음. 상단 높이 PC·아이패드 가로 101px, 태블릿 세로 143px, 모바일 약181~214px. 능력 보기, 활동 변경·새로고침 복원, 재정 펼치기, 중요 선택창, 로그 자동 추적·이전 기록 위치 유지·새 기록 이동을 검수했다. 증거: `.orchestrator/ui-qa/layout-20261014/qa.json` 및 PNG. 실제 iPad Safari 검수는 미실행.

앱 내 브라우저 도구는 초기화 경로 오류로 사용할 수 없어 별도 새 Chromium 컨텍스트와 임시 5217 포트로 검수했다. 사용자 브라우저 저장은 사용하지 않았다. 개발 서버·검수 스크립트는 공개 배포에 포함되지 않는다. 기존 큰 JS 번들 경고가 남는다. 이번 변경의 공개 배포는 미실행.
