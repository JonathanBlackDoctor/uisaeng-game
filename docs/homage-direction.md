# 원작 오마주와 시간 진행 방향

확정일: 2026-10-12. 결정 ID: `homage-realtime-direction-v1`.

## 프로젝트 정체성 — 사용자 확정

**의생게임은 「80억 분의 1」(https://1in8b.life/ko/)의 오마주다. 원작의 시간 흐름, 생애 진행, 선택과 결과, 상태·가족·기록을 확인하는 화면 경험과 분위기를 최대한 비슷하게 따른다. 이를 의대 입학부터 수련·전공·경력·은퇴와 회고까지의 삶에 적용한다.**

원작과의 유사성은 핵심 개발 기준이다. 앞으로 기획·구현·검수는 해당 기능의 원작 동작과 의생게임에서의 대응을 명시한다. 의사 생애 때문에 달라지는 지점은 이유를 기록한다. 원작 분석을 동작 기준으로 재사용하고 새 게임 코드는 독립적으로 작성한다.

## 시간 경험 — 확정 방향

- 플레이 중 실제 시간이 지나면 게임 속 날짜와 나이가 연속적으로 흐른다. 공부·수련·일·생활과 주변 인물의 시간이 하나의 생애 시간축 위에서 이어진다.
- 일시정지와 배속을 제공한다. 중요한 선택을 기다리는 동안에는 시간을 멈춰 내용을 읽고 결정할 수 있게 한다.
- 활동은 시간 속에서 지속되는 생활 방식으로 설계한다. 주활동·보조활동 선택을 유지하면서 활동 기간이 변화와 이력에 연결되도록 구체화한다.
- 입학·진급·시험·수련·전공 진입·은퇴는 흐르는 생애 안에서 도달하는 사건이다. 단 한 번의 선택으로 다음 생애 단계로 건너뛰는 현재 시험 구조는 정식 진행 기준으로 사용하지 않는다.
- 날짜·나이, 상태 변화, 가족과 관계, 누적된 생애 기록을 통해 시간이 흐르는 감각을 전달한다.

“현실에서 시간이 가는 것처럼”은 원작과 같은 연속 진행 경험으로 반영한다. 현실 1년과 게임 1년을 같은 길이로 만들라는 의미로 해석하지 않는다. 앱을 닫아 둔 시간의 자동 진행은 이번에 요청되지 않았으므로 기존의 부재 시간 진행 없음 원칙을 유지한다.

## 확인된 참고 동작과 근거

- 2026-10-12 원작 공식 한국어 페이지(v0.6.63 표시)는 한 생애 길이 약 30·60·90분, 일시정지·배속, 올해의 초점과 인생 기록을 안내한다. 60분 설정에서 1년당 약 40~60초라는 안내는 **원작 설명**이며 의생게임의 확정 수치가 아니다.
- 기존 `research/1in8b/docs/02-simulation.md`는 고정 v0.6.59 소스 분석으로 실제 경과 시간을 받는 진행 함수와 결정 대기·일시정지 시 진행 중단을 확인했다. 과거 버전의 분석이며 현재 사이트의 실제 플레이를 새로 검증한 것으로 표시하지 않는다.
- 기존 `research/1in8b/docs/01-interface.md`의 상태·초점·가족·기록·생애 지도 분석을 화면 대응 설계에 재사용한다. 대량 원본 재조사 대신 필요한 구간과 해시만 인계한다.

## 남은 상세와 구현 경계

1년당 초, 기본 플레이 길이와 선택 가능한 길이, 배속 단계, 입학 시 나이와 은퇴 시점, 기간별 활동 효과·사건 간격은 후속 구체화 대상이다. 기존 30~45분 목표와 원작 설정의 대응도 이 단계에서 정한다. 구현에서는 저장·복원·선택 중복 방지와 함께 시간 중복 적용, 배속에서 사건 누락, 선택 대기 중 시간 진행을 검증해야 한다.

현재 게임은 시험 빌드다. 후속 사용자 승인 `homage-randomness-application-v1`에 따라 새 이야기의 `random-preview-v1`에는 연속 시간·정지·배속·조건부 무작위 사건을 연결했다. 상세와 검증은 `docs/random-life-preview.md`에 기록한다. 이 시험 경로는 정식 시간 배율·생애 규칙·전체 콘텐츠가 완성됐다는 인증이 아니다. 기존 세 초안의 통합 보류, 다른 핵심 수치의 승인 대기, 공개 배포 제외는 그대로 유지한다.
