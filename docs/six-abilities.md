# 상세 능력 6가지 · 2026-10-14

후속 사용자 요청으로 [전공과 능력 시너지](specialty-synergy.md)를 추가했다. 관련 능력과 전공 숙련에 따라 지수가 달라지며 성장·성과 보상·추가 수입이 지수적으로 커지는 시험 설정이다. 이전 최대 3배 선형식은 교체했다.

사용자 승인: 판단력·술기·소통·연구력·운영력·자기관리로 통합하고, 건강·행복·지식·관계와 활동·사건·시작 배경·피로·랜덤의 영향을 유지한다. 사용자는 “좋아 그렇게 구현해”라고 승인했다. 종류와 영향 구조는 승인된 방향이며 가중치·성장량·조건 수치는 조정 가능한 가상 게임 설정이다.

## 계산과 선택

새 게임과 전환된 저장은 능력 스키마 2를 사용한다. 실제 저장·성장·감소·수행력·사건 추첨·전공 지원 계산이 여섯 능력을 사용한다. 기존 30개를 화면에서만 숨기는 방식이 아니다.

| 능력 | 주요 활동과 역할 |
|---|---|
| 판단력 | 공부·사례 검토, 임상 대응과 단서 파악 |
| 술기 | 실습·수련, 지도 아래 처치와 술기 선택 |
| 소통 | 모임·협업·설명, 관계 기회와 갈등 해결 |
| 연구력 | 연구 참여·자료 검토, 연구 기회와 검증 선택 |
| 운영력 | 일·일정·예산 조율, 팀·비용 대응 |
| 자기관리 | 휴식·운동·수면·생활 관리, 피로 부담 완화 |

네 기본 수치는 서로 다른 가중치로 현재 수행력에 모두 반영되고 성장 효율에도 영향을 준다. 피로는 수행력과 성장 효율을 낮춘다. 활동·동아리·생활 습관·관련 사건은 능력을 연습시키며, 오래 사용하지 않은 능력은 취득 실력의 일부를 유지하면서 감소한다. 시작 배경과 시드가 초기 능력을, 재현 가능한 난수가 월 성장과 사건 추첨·성공 여부를 바꾼다.

여섯 능력은 활동 성과, 사건 가중치, 전공 지원 보정에 사용된다. 자기관리는 피로 완화에 사용한다. 각 능력으로 추가 선택이 열리는 사건을 갖는다. 술기용 `ability-technique`를 추가했으며, 낮은 능력에서도 도움받는 선택을 유지한다. 수치와 조건을 조회하는 UI는 난수를 소비하거나 저장을 수정하지 않는다.

## 이전 저장

`ability-schema.ts`의 명시적 대응표가 30개 항목을 빠짐없이 한 번씩 여섯 능력에 배정한다. 각 묶음의 평균을 소수 첫째 자리까지 옮기고 마지막 사용 시점은 가장 최근 시점을 쓴다. 최근 변화는 묶음에서 가장 최근 달의 변화만 평균에 반영한다. 난수 시드·전공 숙련·이미 만난 능력 사건·진행 시점은 보존한다. 재전환해도 값이 달라지지 않는다.

이전 저장은 읽기 시 원본을 수정하지 않고 여섯 능력으로 표시한다. 다음 유효한 연습·시간 진행·관련 선택에서 스키마 2로 저장한다. 이미 열린 이전 능력 사건은 원래의 조건·문구·난수·결과로 해결한 후 전환한다. `abilities-legacy.ts`는 이 검증·정산용 호환 코드이며 새 게임의 능력 계산에 사용하지 않는다. 저장의 임의 문구 수정은 계속 거부한다.

실제 이전 로컬 저장 검수에서 발견한 동기 이름 카탈로그 변경도 호환 처리했다. 기존 민재·윤서는 같은 시작 시드에 대응하는 이름일 때만 허용하며 인물·진로를 다시 추첨하지 않는다.

## 검증과 범위

관련 자동검사 43개(능력 28·시작 배경 8·생애 통합 7) 통과. 30개 일대일 배정, 평균·변화·시드·전공 숙련 보존, 원본 불변·반복 전환, 이전 능력 사건 6종의 정산, 모든 기본 수치의 수행력 영향, 새 여섯 능력의 추가 선택, 배속 일치와 은퇴까지 진행을 확인했다.

실제 5198 로컬 검수에서 이전 30개 능력/동아리 선택 대기 저장을 그대로 복원했다. 연구 동아리 선택 후 새 형식으로 전환·활동 성장·일시정지·새로고침·여섯 수행력과 변화량의 정확한 복원을 확인했다. 390×844/1024×768에서 여섯 항목과 상세 펼침, 가로 넘침 없음, 콘솔 경고/오류 0. 원본 백업과 검수 화면은 `.orchestrator/ui-qa/six-abilities` 및 `.orchestrator/ability-original-save.json`에 보존했다. 신규 6개 능력 사건 모두를 실제 브라우저에서 플레이한 검수와 실제 Safari는 미실행이다.

공유 디렉터리의 전공·선택 개선과 통합한 최종 전체 Vitest 392개 및 Node 37개 통과, 타입 검사와 production 빌드 통과. 전체 회귀 후 변경된 CareerPanel·play-layout UI는 관련 능력·variety-pacing 38개 검사로 추가 확인했다. 전체 회귀 최초 실패 결과는 `.orchestrator/six-abilities-tests.json`, 최종 전체 실행은 `.orchestrator/six-abilities-final-tests.json`, 마지막 UI 실행은 `.orchestrator/six-abilities-final-ui-tests.json`에 보존한다. 결과를 코드 해시와 함께 보존하며 이전 실행을 변경된 코드의 성공으로 간주하지 않는다. 공개 배포는 이번 작업에서 실행하지 않았다.
