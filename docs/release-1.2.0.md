# 의생게임 1.2.0

사용자 지시 “이번에도 수정사항 다 반영해서 배포하는거지?”에 따라 1.1.1 이후 완료된 게임 변경과 금액 표시 통일을 묶는다.

- 병원 확장·대출·불황·운영 위기와 축소·폐업·잔여 부채를 반영한다.
- 여러 플레이의 전공·전문의·분과와 전문 분야를 진료실 도감에 모은다.
- 건강·행복·지식·관계의 이번 생애 최고값과 역대 최고값을 보존한다.
- 장소·복장·소품·그림 변형과 차 마시기·산책·차트 확인 등 장면 동작을 확장한다.
- 새 게임의 성별과 한국어 이름을 3,200개 후보에서 자동 배정하고, 시작한 게임의 이름·성별은 저장·복원 시 유지한다. 기존 저장에는 이름을 소급 배정하지 않는다.
- 선택지·재정 상세·기록·공유의 돈을 반올림 없는 억·만 단위로 통일한다.

현실 제도와 구분되는 병원 위험·금리·규모 등은 조정 가능한 게임 설정이다. 완료된 전체 소스를 새로 고정해 통합 검사·타입·운영 빌드·이전 공개 저장 호환을 검증한 뒤 같은 공개 주소에 배포한다. 개별 작업 검수와 HQ 통합 검수의 범위를 구분하며 고정 이후 새 변경을 이전 성공으로 인증하지 않는다.
