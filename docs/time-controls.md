# 시간 조작과 입학 나이

## 재생 중 배속 변경 수정 (2026-10-13)

0.5초마다 처리하는 시간 진행 저장이 공통 busy 상태를 켜며 네이티브 배속 메뉴를 비활성화하던 문제를 수정했다. 시간 진행 저장은 화면의 조작 잠금을 켜지 않으며, 저장과 겹친 재생/정지·배속 입력은 합쳐서 최신 저장 직후 순서대로 적용한다. 저장 실패·다른 생애·선택 대기·완료 상태에는 대기 입력을 적용하지 않는다. 기존 저장 충돌 검사와 선택 중 시간 정지는 유지한다.

실제 별도 브라우저 origin 5197에서 일시정지 없이 1→4→2→1→2배속을 변경하고, 새로고침 후 2배속·진행 중·활성 메뉴를 확인했다. 저장/시간 조작 테스트 16개, TypeScript 검사 및 별도 production 빌드 통과. 증거는 `.orchestrator/ui-qa/live-speed/qa.json`과 `playback.png`, 빌드는 `.orchestrator/live-speed-build`다. 공개 배포는 하지 않았다.

2026-10-13 사용자 요청으로 16배속, `다음 선택까지`, 새 게임 시작 나이 20세를 반영했다. 이전의 19세 시험 설정보다 우선한다.

- 배속은 1·2·4·8·16배이며 저장·복원된다.
- `다음 선택까지`는 일시정지 상태에서도 사용할 수 있다. 기존 시간 엔진으로 활동·경험·경제·가족·난수 추첨을 처리하고 첫 선택에서 멈춘다. 선택 답변은 자동으로 고르지 않는다. 선택 대기·저장 오류·완료 상태에서는 사용할 수 없다.
- 한 번의 이동은 하나의 저장 액션이다. 기존 저장 충돌 검사를 거치며 중복 호출은 다시 적용되지 않는다. 설정한 배속은 유지하고 도착 상태는 일시정지로 저장한다. 선택 후 시간 시작 또는 다음 선택까지를 누른다.
- 건너뛴 시간은 실제 플레이 활성시간으로 더하지 않는다. 대학 비중 측정에서 합성 시간을 실제 플레이로 인증하지 않는다.
- 새 게임은 시작 나이 20을 저장하고 나이·로그·장면·생애 지도에 동일하게 적용한다. 시작 나이 필드가 없는 기존 저장은 19세 기준을 유지한다. 과거 기록을 다시 쓰거나 기존 진행을 초기화하지 않는다.
- 단계별 게임 기간은 바꾸지 않았으므로 새 게임의 기본 회고 시점은 77세다. 수련 지연에 따른 기존 기간 연장은 유지한다.

검증: Node 37개, Vitest 89개(기존 83+새 6), TypeScript, Vite 빌드 통과. 새 검사는 1배/16배/다음 선택의 같은 결과, 전체 미수련 경로의 월별 돈·난수·필수 선택, 중복 방지, 일부 월 진행 후 이동, 활성시간 보존, 새·기존 시작 나이, 16배속 및 선택 저장 복원을 확인한다. 실제 브라우저 별도 origin `http://127.0.0.1:4320/game/`에서 20세 시작·16배속 선택·동아리 첫 선택 도착·새로고침 복원·응답 후 일시정지 및 배속 유지를 확인했다. 390px 요청의 실제 스크린 콘텐츠 폭375px와 PC1280px에서 가로 넘침 없는 시간 조작을 확인했다. 기존4317/4318 저장은 변경하지 않았다.
