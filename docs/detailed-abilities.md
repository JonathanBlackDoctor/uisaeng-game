# 상세 능력 구현

2026-10-13 사용자 직접 승인: 상단 건강·행복·지식·관계를 유지하고, 능력 보기 팝업에서 세부 능력을 확인한다. 6분야 30개 능력과 전공별 숙련을 구분한다. 이전 대화의 내부 6역량 철회는 이 요청의 구현을 제한하지 않는다.

능력의 축적값과 현재 수행력은 별개다. 현재 수행력은 네 스탯과 피로를 반영하며 컨디션 저하가 축적값을 직접 지우지 않는다. 활동·생활 옵션·동아리·일상 소식·선택 사건이 실력을 키운다. 장기간 미사용한 능력과 일부 실패 경험에는 감소가 있고, 반복 경험은 점차 성장폭이 작아진다. 대학의 임상 기술과 전공 숙련에는 경험 단계별 상한이 있다.

상세 능력은 기존 활동 성과 추첨과 피로 부담, 일상·관계 사건의 가중치, 전공 지원 준비 점수에 반영된다. 능력 전용 6개 사건은 일정 충돌·팀 합의·자료 검토·실습 인계·회복·예산 조정이며, 충분한 역량으로 추가 단서와 선택이 열린다. 낮은 역량에도 도움을 구하는 경로가 남는다. 환자의 사망·소송 확률을 능력에 직접 환산하지 않는다.

팝업은 기본 화면과 선택 카드에서 열 수 있다. 열람 중 시간은 멈추고 닫으면 이전 진행 상태를 유지한다. 전공 숙련은 실제 탐색·실습·수련 기록과 연결하며 자격과 면허를 대체하지 않는다.

저장: `GameState.abilities`는 선택적 필드로 추가한다. 이전 저장은 유효성을 유지하고 현재 시점에서 동일한 시작 시드로 초기화한다. 과거 실력 상승을 소급해 만들어내지 않는다. 기존 대기 사건은 보존한다. 능력 전용 난수 상태를 저장하며 화면 열기·닫기로 난수를 소비하지 않는다. 진행과 선택 중복 방지는 기존 액션 ID와 월 처리 경계를 따른다.

`ABILITY_RULES`와 세부 계수·임계값은 현실 측정값이 아닌 변경 가능한 provisional 게임 설정이다. 사용자가 승인한 것은 작동 구조와 구현이며 정확한 숫자의 정식 균형 승인이 아니다.

작업 범위: 사용자 직접 지시에 따라 abilities 모듈·팝업·검증을 추가하고 공통 contracts/main/career-runtime에 필요한 연결을 수행한다. 기존 finance/lifestyle/portfolio·기관 콘텐츠와 다른 작업의 변경을 보존한다. 자동 큐 배정·배포는 이 채팅에서 하지 않는다.
