# 결과 공유

2026-10-13 사용자 요청: “네이티브 공유 기능 구현해”. 독립 작업 채팅 `01a132c3-967f-7851-914e-2cf695035517`에서 구현했다. 자동 큐 배정이나 HQ 교체는 하지 않았다. context-check가 반환한 교체 신호는 별도 활성 HQ011의 샘플이다.

종료 화면과 생애 기록·보관된 회고의 상단에 `결과 공유하기`를 표시한다. 종료 나이, 전공·진로, 건강·행복·지식·관계, 기록 수와 공개 게임 주소를 텍스트로 공유한다. 저장 파일, 개별 사건 본문, seed, 로컬 미리보기 주소는 포함하지 않는다. 이미지를 생성하거나 서버에 회고를 업로드하지 않는다.

버튼 클릭 직후 navigator.share를 호출하여 사용자 활성화를 유지한다. API 미지원/canShare=false는 클립보드 복사, 복사 거부는 선택 가능한 텍스트 상자로 처리한다. AbortError는 조용히 종료한다. 다른 공유 오류는 별도 복사 버튼을 제공하며, API 성공을 실제 메시지 전송 완료로 표시하지 않는다. 같은 컴포넌트의 중복 클릭을 막고 저장 데이터는 변경하지 않는다.

기준: https://www.w3.org/TR/web-share/ . 대상 앱 목록은 운영체제·브라우저·설치 앱에 따라 달라진다. 카카오 SDK 연동이나 특정 앱 강제 호출은 없다.

수정 범위: game/src/main.tsx의 연결, ResultShare.tsx, result-share.ts, result-share.css, game/tests/result-share.test.tsx, game/tests/browser/result-share.html 및 tsx. 별도 의존성·잠금·공통 계약 변경 없음.

검증: 공유 테스트 9개, TypeScript, Vite 빌드 통과. 샌드박스에서 Vitest/Vite realpath EPERM 발생 후 승인된 외부 샌드박스 실행으로 통과했다. Vite의 500kB 청크 안내는 남아 있다. 저장 데이터와 분리된 브라우저 fixture에서 PC와 390px 모바일 화면, 네이티브 API 모의 호출, 취소, 실패 후 복사, 자동 복사, 권한 거부 후 수동 복사, 다른 보관 회고의 건강 12 반영을 확인했다. 모바일 가로 넘침 없음, 브라우저 console warning/error 0. 기존 게임 저장에는 접근·쓰기하지 않았다.

공개 사이트에는 아직 배포하지 않았다. 실제 휴대폰 OS 공유 시트와 카카오톡 전송은 미검증이며, 모의 검증을 실제 전송 성공으로 간주하지 않는다. 생애 규칙·콘텐츠의 기존 미정 사항은 유지한다.
