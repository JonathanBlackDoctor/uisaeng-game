# 결과 공유

## 2026-10-15 가족·논문과 실제 사건 공유 (1.4.3)

사용자가 재설계안을 보고 “배포해”로 구현·배포를 승인했다. 가족과 보낸 시간·발표한 논문을 복원하고 주력 능력·인생 최고점을 제거했다. 0건도 그대로 보여 주며 기존 저장의 집계 시작 이후·집계 전 표시는 유지한다.

구성: 🩺 제목+별명 / 직군·진로·나이 / 진료·돌봄·순자산 / 가족 시간·논문 / 4스탯 / 🎬 실제 사건 한 줄 / 게임 링크. 별명은 가족 1,000시간 이상+논문 5편 이상이면 ‘논문 쓰는 가족파’, 실제 확장 계약 2회 이상이면 ‘원장님, 또 확장이요?’, 논문 20편 이상이면 ‘마감과 평생 동행’ 순으로 하나를 고른다. 해당하지 않으면 ‘이번 생의 기록’이다. 임계값은 변경 가능한 문구 표현 설정이며 게임 규칙을 바꾸지 않는다.

사건은 저장된 stories.decisions의 실제 선택에서 고정된 우선순위로 한 줄을 고른다. 동아리 예약 중복·발표 그림 누락·룸메이트 소등 협상·퇴근 후 알림 끄기·도서관 책 대출·산책 벤치·노트 인계 중 알려진 선택만 사용한다. 후일담 결과를 말하는 벤치·노트 인계는 followed가 확인된 경우에만 표시한다. 없으면 사건 줄을 생략한다. 같은 기록은 같은 문구이며 개인 이름·자유 본문·논문 제목·seed는 공유하지 않는다. 이모지는 최대 두 개, 문구는 8줄 이하다. 네이티브 공유와 복사는 동일 본문을 쓰고 취소·실패 동작 및 저장 형식은 유지한다.

현재 로컬 구현이며 1.4.3 고정본 검사와 공개 배포 확인은 별도 릴리스 검증 기록에 남긴다. 이전 배포 기록은 당시 구성이다.

2026-10-15 후속: 공유 문구를 `의생게임 · 이번 생의 기록` 제목, 직군·진로·나이, 누적 진료/돌봄·순자산, 네 가지 스탯으로 정돈했다. 사용자 추가 지시로 저장된 능력의 최고 항목을 주력 능력으로, 시작부터 집계한 최고 스탯을 인생 최고점으로 보여준다. 실제 취득한 전문간호사 자격 또는 실제 발표한 논문 중 한 가지 성과도 넣는다. 자료가 없거나 성과가 0이면 해당 행을 생략하며, 부분 집계 최고치를 인생 전체 기록으로 표시하지 않는다. 0개월은 생략하고 실제 금액·스탯 반올림은 유지한다. 성별·병역·가족 집계·로그 개수는 공유문에서 제외했다. 이 정보의 게임 내 기록은 유지한다. 네이티브 제목은 의생게임, 복사 본문은 같은 내용과 공개 URL이다. 버튼과 상태 문구를 기록 공유/복사로 통일했다. 취소·실패·복사 동작과 저장 형식은 유지한다. 1.4.2 배포 검증은 별도 기록을 따른다.
