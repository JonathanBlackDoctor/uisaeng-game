# 의생게임 1.3.0

의대 입학부터 은퇴까지, 진로와 일상을 선택하는 생애 시뮬레이션 게임입니다.

[게임 플레이](https://jonathanblackdoctor.github.io/uisaeng-game/)

건강·행복·지식·관계를 관리하면서 대학 생활, 전공 선택, 수련, 직업과 은퇴를 경험합니다. 시간은 계속 흐르고 중요한 선택에서는 멈춥니다. 인물·사건·수치는 창작 설정이며 실제 의료 제도나 개인의 삶을 예측하지 않습니다.

## 실행과 검증

Node.js 24와 pnpm 11.25.0을 사용합니다. game 폴더에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

기본 로컬 경로는 /game/이며, GitHub Pages 빌드는 VITE_BASE_PATH=/uisaeng-game/을 사용합니다. GitHub Actions가 테스트·빌드 후 기존 공개 주소에 배포합니다. 산출물은 game/dist입니다.

## 저장과 업데이트

진행은 현재 브라우저에 자동 저장됩니다. 앱을 닫은 동안에는 시간이 흐르지 않습니다. 저장 기록 백업으로 JSON을 내려받을 수 있습니다. 클라우드 동기화와 백업 가져오기는 제공하지 않습니다.

새 버전이 있으면 작은 알림이 표시됩니다. 업데이트를 선택하면 진행을 저장하고 새 버전을 적용합니다. 저장 실패나 다른 탭의 변경이 있으면 적용을 중단합니다. 이전 저장은 유지하며 내부 저장 형식 식별자는 호환성을 위해 보존합니다.

## 1.3.0 변경 사항

사건·선택·기록 문구와 기록 밀도, 기본/짧게 분량 선택, 상단 시간·생활 설정, 능력에 따른 수행과 시작 설명, 돌발 사건의 큰 영향과 기록 강조를 통합했습니다. 수치 반올림 표시와 입학 통지서 동작도 포함합니다. [1.3.0 릴리스 기록](../docs/release-1.3.0.md)을 참고하세요.

## 1.2.0 변경 사항

병원 확장과 레버리지, 진료실 도감, 생애 최고 기록, 생활 장면과 동작, 반올림 없는 억·만 금액 표시를 통합했습니다. [1.2.0 릴리스 기록](../docs/release-1.2.0.md)을 참고하세요.

## 1.1.1 변경 사항

1.1.1에서는 생애 지표의 길러낸 제자를 발표한 논문으로 교체했습니다. 연구 진행·논문 완성·제목·발표 기록을 저장하고 회고·공유 결과에 표시합니다. 기존 제자 기록을 논문으로 환산하지 않습니다. [1.1.1 릴리스 기록](../docs/release-1.1.1.md)을 참고하세요.

## 1.1.0 변경 사항

상세 능력 6종과 전공 시너지, 전공·분과·교수 진로, 성별·병역, 돌발 사건 50종과 의료 분쟁, 가족·제자 기록, 선택과 진행 분량, 생활 장면과 화면을 통합 개선했습니다. [릴리스 기록](../docs/release-1.1.0.md)을 참고하세요.
